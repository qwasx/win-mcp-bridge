## 第十二步（v0.12）：性能大修 + 建筑贴图 + 去掉序章

### 一、卡顿优化
- **地表缓存**：完整的地表着色器不再每帧全屏重算。它画进一张比屏幕大一圈的缓存（四周各留 1/4 长边的余量），每帧只采样一次。
  - 镜头靠近缓存边缘、缩放变化超过 7% 或换季时，才在后台缓冲里分 4–6 条、逐帧渐进重画，画完再与前台交换。
  - 重画会按镜头速度预判前进方向。瞬移或大幅缩放时一次画完。
  - 镜头静止时，地表几乎零开销。
- **水面动画拆出**：河水流纹、细水线、岸边白浪、海面焦散、弧形浪纹、碎金、浪花，改在后期着色器里每帧只算水面像素。
  - 缓存里只存静态底色与水面参数（河：沿程/横向坐标与水深；海：离岸距离/深浅）。
  - 沿程坐标按噪声周期（1920）取模，无接缝。
- **精灵后台生成**：山（单座约 40ms）与树（含 getImageData 回读）改到 Web Worker（OffscreenCanvas）里生成，以 ImageBitmap 零拷贝传回，主线程不再因新山新树进入视野而顿一下。
  - Worker 不可用（老浏览器、Node 测试）时，自动回退主线程生成。
  - Worker 内联打包，双击 index.html 也能用。
- **分辨率上限下调**：
  - 世界层默认 ≤1.5× 像素比，后期输出与世界层同分辨率；高分屏不再按 2× 跑整套后期。
  - 自动降档更积极：每 2.5 秒检查一次，低于约 48 帧就降一级（共 3 级：世界层像素比、地表缓存分辨率、特效档）。
- **F3 性能面板**：显示以下数据。还卡的话，按 F3 截图发我即可。
  - 最慢一帧、卡顿次数（>50ms）；
  - GPU 耗时（EXT_disjoint_timer_query_webgl2）；
  - 地表缓存尺寸与重画次数；
  - 后台精灵生成情况；
  - 自动降档级别。

## 第十一步（v0.11）：地表全面重绘 —— GPU 程序化地面 + 流水（`src/gl/ground.ts`）

旧地面是 Canvas2D 预烘焙的低分辨率分块（每 1024 世界像素只有 384 像素，放大后发糊、平涂、像塑料），
现在改为每帧一次全屏着色器，按世界坐标逐像素绘制，任何缩放都清晰、无平铺重复：

- **草甸**：水彩晕染块（边缘积色的“水痕”）+ 三层网格的手绘草丛（叶根深、叶尖亮、随风轻摆、成簇疏密）+ 野花 + 轻微起伏光影。
- **群落**：林下苔藓与落叶、山地碎石与岩板（细胞噪声）、天澜草原的风吹草浪、荒漠沙丘（脊线明暗 + 风纹）、雪原（吹积雪檐、冰晶闪烁）、冬季原野薄雪露出枯草。
- **田畴**：城镇周边按季节变化（春油菜花/青苗、夏稻田水光、秋金黄与收割后的茬地、冬翻耕），垄沟、田埂；与 `Terrain.inField` 同构。
- **官道小径**：夯土路面、车辙、路中踩亮、小径中间的草、碎石子、路肩踩秃、淡墨路缘。
- **河流**：源头窄、入海宽；湿泥 → 卵石滩的河岸；深浅水色、顺流卷动的水纹和细水线、近岸白浪、浅处透出沙底；两条河汇流处用有符号距离平滑并集，无接缝；干笔河岸墨线。
- **海湖**：近岸浅、远海深；浅水沙底 + 焦散；传统弧形浪纹（错落、一起一落、随风漂移）；日光碎金；一道道推向岸的浪花；干笔岸线。
- 海岸线与 CPU 判定逐位一致：新增可移植哈希 `hashU/pnoise`（`core/rng.ts`，GLSL 用 uint 复刻），`isLand/visLand/inField` 都改用它。
- 合成：Canvas 世界层改为透明，GPU 地表垫在下面（后期着色器里预乘合成）；不再烘焙分块，CPU 省下大量时间。
- `?gl=0` 仍走旧的 Canvas 分块底图；`?ground=0` 只关 GPU 地表。
- 工具：`tools/shots.mjs`（一次启动浏览器连拍多处地表，可指定季节、自动找海岸），`tools/compare.ts`（前后对比图）。

## 第九步（v0.9）：WebGL 渲染 + 特效 + 打击感 + 境界压制
- **渲染管线**（`src/gl/`）：世界仍由 Canvas2D 代码绘制，再作为纹理交给 WebGL2：
  - `stage.ts`：一次全屏后期合成——冲击波扭曲、昼夜调色、**神识圈外记忆水墨**（边缘晕染墨丝流动）、云影/迷雾、雾/沙/闪电、纸纹、暗角、受伤血晕；
    旧版每帧要 8~10 次全屏 Canvas2D 合成，现在合为 1 次着色器，是“卡”的主因之一。
  - 特效画进 HDR 帧缓冲，三级降采样泛光（bloom）；柔和压高光，避免发白成团。
  - `atlas.ts`：32 种代码生成的特效笔触（光核、火舌、剑形、弧斩、雷电剖面、法阵、八卦、墨溅、冰晶……），无任何贴图文件。
  - `fx.ts`：6000 粒子池 + 拖尾条带 + 分形闪电 + 冲击波；预设：命中、爆炸、墨溅、余烬、烟。
  - `combatgl.ts`：所有法术/弹道/领域重做（火球带火舌余烬与烟、火蛇摆尾、剑芒带剑形与剑气拖尾、天雷分叉闪电、冰锥晶光、地刺破土、剑雨、法阵旗光柱……）。
  - 神识圈的纹理交给 GPU 旋转缩放（mipmap 三线性过滤），彻底丝滑。
  - 不支持 WebGL2 的设备自动回退到旧的 Canvas2D 渲染；设置里可切换。
- **画质**：自动（持续掉帧时逐级降低世界层分辨率 → 关泛光 → 粒子减半），或手动 高/中/低；手机默认分辨率上限 1.5×。**F3** 显示帧率与耗时。
- **打击感**：命中白闪、击退、顿帧（暴击/击杀 40~90ms）、震屏（创伤值平方衰减）、重击色散；敌人近战前地面**红色预警**；**空格闪避**（0.2 秒冲刺 + 无敌帧，0.85 秒冷却）。
- **境界压制（原著：越大境界几乎必死）**：打高一大境界只剩 6% 伤害（符箓 30%），被高一大境界打承伤 ×3.2；
  已察觉你的高境界敌人靠近时有**威压**：减速、警示“速逃”。

- **原著大事件**按年份发生、提前一年传闻：升仙大会（第 2 年，太南小会，买令或擂台三连胜）、血色禁地（第 4 年起每 5 年）、
  燕家堡之变（第 9 年）、魔道六宗入侵越国（第 12 年起两年：先在越国斩魔修 25 名，再到黄枫谷击败鬼灵门长老；
  否则越国沦陷，城镇被魔道占据）、虚天殿（第 20 年）、坠魔谷（第 32 年）。错过或失败都会改变世界，J 大事记可查看。

## 第三步：战斗与法术
- **快捷栏 9 格**（数字键 1–9），任意法术 / 法器可放任意格；K 打开法术书分配。触屏为右下 3×3 法诀盘。
- **瞄准**：PC 鼠标指向即瞄准；鼠标不动 2.5 秒后自动锁定最近敌人；点击敌人可手动锁定（红圈）。
- **法术库 69 门**（`src/data/arts.ts`），14 系：火 / 冰 / 雷 / 风 / 土 / 木 / 剑诀 / 炼体 / 御兽召唤 / 魔道 / 神识 / 阵法 / 身法 / 符宝。
  - 品阶 凡 / 黄 / 玄 / 地 / 天，有境界要求；开局 7 门（气劲掌、火弹术、风刃术、御风诀、回春术、神识外放、敛息术）。
  - 熟练度 初学 → 小成 → 大成 → 圆满：威力、范围、异状几率、冷却逐级提升，并有形态变化（如火弹术 1→2→3 发，火蛇化蛟）。
  - 原著神通：青元剑芒、护体剑盾、剑影分光术、巨剑术、大庚剑阵（需青竹蜂云剑）、辟邪神雷、金雷竹雷、乾蓝冰焰、元磁神光、梵圣真魔功、噬金虫群、啼魂兽、傀儡……
  - 法术散落天下：妖兽 / 魔修掉落卷轴，洞府遗迹首次探索得宝（会惊动守护），在储物袋中「研读参悟」习得。
- **异状**：燃烧、冰冻、麻痹、中毒、定身、击退、破甲（另有迟缓、眩晕）。
- **连携**：冰冻 + 雷 = 冰裂雷爆（×2.2）；定身藤 + 火 = 藤燃燎原；燃烧 + 风 = 火借风势蔓延；中毒 + 火 = 毒焰爆；麻痹 + 冰 ×1.5。辟邪神雷等对魔物鬼物额外伤害。
- **敌人 27 种**（`src/data/enemies.ts`，妖兽代码绘制 `src/gfx/beast.ts`，15 种体型）：按区域、地貌（雪原 / 沙漠 / 海域 / 林地 / 魔域 / 草原）、危险度刷新；城镇宗门附近不刷怪；夜里更多。
  - 境界压制：低一个大境界伤害 ×0.55，高一境 +30%；越阶有险，但可胜。名牌颜色提示强弱。
- **法器**：储物袋 → 放入快捷栏即可驱使（飞剑、飞针、法印……）；护甲、盾、飞行法器为「祭出 / 收起」。
- **倒下**：不会坐化——损失一成当前境界修为、一成灵石与一两样物品，三日后于最近城镇醒来。
- 脱战 6 秒后自动回复气血法力；重伤时屏幕泛红。

## 代码结构
- `src/world/npc.ts` 人界 NPC：生成、离屏模拟、神识察觉、行为、斗法、对话
- `src/world/town.ts` 城镇设施、商店、传送阵、拍卖、宗门
- `src/world/hearts.ts` + `src/data/beauties.ts` 红颜故事线与好感
- `src/world/events.ts` 原著大事件时间线、神识内奇遇
- `src/ui/ModalLayer.tsx` 对话框（立绘 / 代码半身像）、商店、城镇、拍卖、红颜录、大事记
- `src/world/combat.ts` 战斗核心：施法、弹道、区域、异状、连携、敌人 AI、刷怪、掉落、倒下
- `src/world/combatfx.ts` 法术特效、敌人与血条绘制
- `src/ui/CombatUI.tsx` 快捷栏、法术书
- `src/gfx/character.ts` 7 头身骨骼角色：分件绘制、布料/发带物理、8 方向平滑转身，动作 idle/walk/run/fly/sit/cast/hit/dodge/gather（第三步战斗复用）
- `src/gfx/mountain.ts` 程序化水墨山：青绿/浅绛/雪山/魔域/丹霞/海岛/丘陵/喀斯特，多层远近、皴笔、山脚云雾、峭壁、瀑布、山径、亭台、峰顶积雪
- `src/gfx/tree.ts` 12 种树（松、柳、竹、枫、黄枫、梅、桃、柏、雪松、枯树、椰树、阔叶），四季变化
- `src/gfx/building.ts` 殿、檐、塔、牌坊、台阶、城墙组合出各宗门/城镇/村落/港口，护山大阵
- `src/gfx/grass.ts` 草丛（7 种 × 8 变体 × 四季，位图缓存 + 斜切摇摆）
- `src/gfx/sprites.ts` 位图 LRU 缓存 + 每帧限时生成
- `src/world/terrain.ts` 人界地形、山脉、林带、河流道路、地形明暗
- `src/world/life.ts` 鸟群、仙鹤、鹿兔、蝴蝶、萤火、鱼跃、舟船、行人商队、御剑修士
- `src/world/weather.ts` 晴/雨/雷雨/雪/雾/风沙
- `src/world/cultivation.ts` 修为、瓶颈、突破、天赋、寿元、背包、掌天瓶、炼丹
- `src/world/nodes.ts` 采集点
- `src/world/render.ts` 分层渲染、Y 排序、倒影、昼夜灯火
- `tools/` Node 截图工具（@napi-rs/canvas）：`npx tsx tools/shot-game.ts out.png qixuan 0.8`
