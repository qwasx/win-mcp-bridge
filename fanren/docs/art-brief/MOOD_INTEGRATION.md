# v0.47 Mood Integration

## Source and Scope

The owner supplied v0.46 game source and the `mood-textures-23` archive. Its manifest contains 23 images, not 24. The original drafts were RGB, had inconsistent dimensions, and several included painted checkerboards. The preparation script performs pigment extraction, mask cleanup, straight-alpha output, explicit sRGB tagging and boundary-strip blending. The unusable vignette matte is reconstructed procedurally, with the center 70 percent fully transparent.

No existing ground, character, monster or building art is replaced. Existing binary imports are converted to external same-origin URLs to make the integrated production build fit a 2 GB workspace. Audio loading accepts external URLs through `fetch` and preserves the original synthesized fallback.

- Strict TypeScript check passes. The supplied source had strict mode disabled; eight compatibility issues and React 19 callback-ref returns were corrected. Debug-only unused locals remain allowed.
- 6,006 time/weather samples pass bounds, continuity and cycle tests. Palette and lunar-phase anchors pass.
- All 23 files are genuine RGBA PNG at target size with an explicit sRGB chunk. Transparent patches have transparent pixels. Tile edges match at pixel level; no 2x2 replication is used.
- Red-background and 50-percent offset review sheets are generated locally.
- Browser smoke test covers four title moods, guide/escape, contemplation, sound, settings, mobile layout, original game launch, preserved player, lake details, photo mode, actual PNG export, state restoration and original save.
- No browser runtime exceptions or missing resources were observed in the smoke run.

## Performance and Art Review

The included `tools/gpubench.mjs` uses warmed, alternating mood-on/off pairs and `gl.finish()` in headless Chromium with SwiftShader. The initial 960x540 / 48-pair run measured a median incremental frame cost of 0.20 ms, but p95 was 12.50 ms and the environment has no physical GPU. These numbers do **not** certify a less-than-1-ms regression on the player's GPU or at all resolutions. Repeat on target hardware.

The final production 960x540 / 60-pair run measured 0.10 ms paired median regression and 9.90 ms p95. Mood drawing CPU time was 0.10 ms median and 0.30 ms p95. Production WebGL smoke, original movement, exact photo-state restoration, PNG file signature, save-leak protection and Canvas2D clear/rain/snow/fog compatibility all pass. A separate clean restoration of the code-only distribution also passes. Machine-readable reports are in `verification/`.

Four actual-world captures and four title compositions are generated by the smoke test. The in-game camera remains the original top-down projection; this update does not turn it into a perspective landscape engine. Whether every capture is wallpaper-worthy still requires the owner's visual acceptance. Treat this release as an integration preview, not final art sign-off.
