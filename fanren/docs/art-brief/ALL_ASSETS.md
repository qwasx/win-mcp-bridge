## 0. 总览：做什么、按什么顺序、怎么交

### 0.1 游戏是什么（30 秒版）

- 《凡人修仙传》开放世界 2D 游戏，主角韩立。浏览器运行，WebGL 渲染。
- 画面：**水墨淡彩**的大地图，俯视略斜。山是程序生成的青绿山水（负责人很喜欢，是画风锚点），树也由程序画。
- 三张大地图：
  - **天南**：越国、元武国、车骑国、紫金国，魔道六宗地界，慕兰草原，天道盟。
  - **乱星海**：群岛与大海；天星城、星宫、魁星岛、外星海。
  - **大晋**：中原、北方雪原、南疆毒瘴之地、昆吾山。
- 地图上有 14 座城、600 多个小镇村落、22 个宗门、数百处险地和秘境，以及几处原著名场景：坠魔谷、血色禁地、虚天殿、昆吾山、阴阳窟。

### 0.2 负责人最在意的（排序即优先级）

1. **地面**：要好看、精致、有水墨气息。这是他一直不满意的地方。
2. **建筑**：要做得非常非常好，**尤其是城镇和宗门内部**。走进一座城、一个宗门，要有身临其境的感觉。
3. **妖兽**：用贴图，要有凶性和灵气。
4. **特效**：负责人把「特效好看」列为全游戏第一优先。
5. 法宝要和原著对得上，拿到法宝要有满足感。

### 0.3 不要做的

| 不要做 | 原因 |
|---|---|
| 树木 | 程序画。负责人认为贴图树「太乱太杂」 |
| 山 | 程序画，负责人很喜欢，不能动 |
| 人物：身体、衣服、动作 | 程序画 |
| 人物头像和立绘 | 已有，不要新做 |
| 云、雨、雪、雾、昼夜、水面 | 程序做的天气系统，负责人很满意 |
| UI 界面框、按钮、面板 | 程序做 |
| 任何文字 | 匾额、招牌、旗帜、碑面、书页一律留白，程序会写字 |

> **画面里需要树的地方**（例如民居院里、宗门里），只画一个**很简单、很淡的树冠剪影**，或者干脆不画，留出位置。宁可不画，不要画得复杂。

### 0.4 推荐生产顺序

**A 地面 → B 妖兽 → C 建筑 → E 名地构件 → D 小物件 → F 法宝 → G 特效 → H 图标**

- **每完成一类（或一类中的一大批）就提交并推送一次**，不要攒到最后。程序员会边收边接入。
- **不需要等程序员验收再继续**，一直往下做。程序员如果发现问题，会在仓库里写 `FEEDBACK_FULL.md`。你每推送一批之前，看一眼这个文件是否存在、有没有新内容，有就先改。

## A. 地面

地面是负责人最在意的。目标是：**像一幅淡彩长卷铺在地上**——有笔触、有干湿浓淡、有纸感，但安静、不抢戏，人和房子要能从地面上「跳出来」。

### A1. 无缝材质

**规格（同 1b，必须严格遵守）：**
- 正上方垂直俯视，没有透视、没有地平线、没有任何「立起来」的东西。
- 1024²（标注 2048² 的除外），**四边无缝**。
- **整张内容独一无二**：没有明显的重复中心、没有贯穿条带。自检用左右两个半幅互相比较，RMSE 要大于 3%。
- 明度比建筑低半档、饱和度低一档。
- 每张附一张 3×3 平铺自检图：`<文件名>_tile3x3.jpg`。
- 同一材质要多张变体时，用 `_a`、`_b`、`_c` 区分。各变体之间色调一致，但内容不同（程序会混合使用，消除重复感）。

## B. 妖兽、环境动物、灵宠、召唤物

**规格（同 1b）：**
- `person_px: 320`：一个人在这张图的比例下高 320 px。
- 侧面，俯视约 20°，**头朝右**。四条腿都要能看到或能读出来。
- 透明底，不画落地投影。
- 普通妖兽最长边 ≥ 600 px；BOSS ≥ 1200 px。
- **每个 id 两张：`<id>_idle.png`（待机 / 行走）和 `<id>_attack.png`（攻击）**。两张必须是同一只：同样的配色、花纹、特征，只换姿态。
- BOSS 可以多交一张 `<id>_charge.png`（蓄力）。
- 程序会让身体做呼吸、扭动、扑击等动画，所以**身体轮廓要清楚、四肢不要和身体糊在一起**。

**姿态约定：**

| 类别 | 待机 / 行走（idle） | 攻击（attack） |
|---|---|---|
| 四足兽 | 行走中，一侧前腿迈出 | 前扑、张口 |
| 蛇、蛟类 | 盘曲抬头 | 前探噬咬或喷吐 |
| 飞禽 | 展翅滑翔的侧面 | 收翼俯冲、伸爪 |
| 虫类 | 爬行 | 举螯、喷射、抬尾 |
| 鬼物 | 漂浮 | 前扑、伸爪；保留真实半透明 alpha |
| 鱼类（海中） | 侧面游动 | 张大口扑咬。程序会让它从水面跃出 |
| 人形（尸、夜叉） | 站立微前倾 | 扑抓或挥击 |

**manifest 字段：**
- `anchor`：四足中心在地面上的投影点。

## C. 建筑（全部地域）

**这是负责人第二在意的部分。** 要求：**城镇和宗门内部要做得非常好**。走进一座城，要有街巷、店铺、民居、城楼层次分明的感觉；走进一个宗门，要有山门、广场、主殿、偏殿、楼阁、庭院的纵深。

### C0. 建筑通用规格（同 1b）

**画法：**
- **正面 + 俯视约 30°，平行投影**（宋代界画式）：正立面完整可见，屋顶坡面也可见，没有灭点。
- **不要转成 45° 斜角。** 侧墙可以露一点点厚度，但正面必须平行于画面。
- 对称的建筑就画成对称。

**比例：**
- `person_px: 215`（一个人高 215 px）。
- **门高约 1.5 人（约 320 px）**，这是检查比例最直观的一条。
- 表中的「宽度参考」是图片宽度，可以 ±15%。

**细节：**
- 要画台基、台阶、柱础、墙根、檐下阴影、瓦当、斗拱。可以做旧，但不要破败（除非是遗迹）。
- 透明底，不画落地投影。
- 匾额、招牌、幌子、对联、旗帜**全部留白**（程序写字）。

**manifest 字段：**
- `anchor`：正面中轴线与地面的接触点（台基最前沿的中点）。
- `door_height_px`：门的像素高度。
- **`footprint`**：建筑**实际占地**的矩形 `[x, y, w, h]`（像素坐标）：从正面看台基压在地面上的范围，程序用它做碰撞。
- `door`：门洞中心点 `[x, y]`。可以走进去或穿过的建筑（城门、山门、院门）要写。

**变体：** 标「×2」的做两个变体，让街道不重复。变体之间结构相近，但屋顶、门窗、装饰、色彩做区分。

**接缝件**（院墙、城墙、篱笆）：左右两端必须能无缝拼接，并在 manifest 写 `"tileable_x": true`。

## G. 特效序列帧

**负责人把「特效好看」列为全游戏第一优先。** 现在的特效都是程序画的粒子和几何形状，要换成手绘序列帧，做出「水墨飞溅 + 淡彩辉光」的效果。

### G0. 特效规格

**画风：** 水墨淡彩的特效。
- 墨迹飞溅、笔触的拖尾、宣纸上晕开的颜色，加上灵光。
- **不要**西方魔幻游戏那种霓虹光效，**不要**卡通爆炸星形。
- 参考：国画中的火焰、云气、水纹的画法；武侠动画中的水墨特效。

**格式：**
- 一个特效 = **一张图集 PNG**：所有帧排成网格。
- 每行最多 8 帧，从左到右、从上到下播放。
- 单帧 **256×256**（小特效）或 **512×512**（大特效），帧与帧之间不留空隙。
- 透明底，直通 alpha。
- 另附一张 GIF 或 MP4 预览（`<id>_preview.gif`），方便检查。

**manifest 写：**

```json
{ "file": "vfx/fx_fireball.png", "type": "vfx", "id": "fx_fireball",
  "frame": [256, 256], "cols": 8, "frames": 12, "fps": 24,
  "loop": true, "blend": "add", "anchor": [128, 128], "orient": "right" }
```

字段说明：
- **`loop`**：`true` = 循环播放（飞行中的弹道、持续的光环）；`false` = 播一次（命中、爆炸）。
- **`blend`**：
  - `"add"`：纯光效，程序用叠加混合（越叠越亮）。这类特效**不要有深色**，暗部直接透明。
  - `"normal"`：有墨色、烟尘、实体的特效，正常混合。
- **`orient`**：弹道类画成**朝右飞行**（头在右，拖尾在左），程序旋转。
- **`anchor`**：
  - 弹道类：弹头中心。
  - 命中、爆炸类：爆点中心。
  - 光环类：画面中心。

**帧数：**
- 弹道循环 8～12 帧；命中 / 爆炸 10～16 帧；光环循环 12～16 帧。
- 第一帧和最后一帧要能自然衔接（循环类）或自然消散（单次类）。

**颜色：** 每个技能在游戏里有一个主色（`lists/skills.csv` 的 `color_rgb` 列），特效主色要和它接近。

### G1. 技能特效：按弹道类型

游戏有 72 个技能，按「特效类型」归成下面这些。**每种类型做 1 组**，同类型的技能程序会换色复用。

**每组的构成：**
- **弹道**（`fx_<类型>`）：循环，飞行中显示。
- **命中**（`fx_<类型>_hit`）：单次，打中时播放。
- 「范围 / 持续」类改为一张**持续区域图**（`fx_<类型>_field`，循环）。

| 类型 id | 用于哪些技能 | 画什么 |
|---|---|---|

### 3.2 manifest.json

**一个总清单**，每推送一批就把新文件追加进去。格式：

```json
{
  "version": "full",
  "person_px": 320,
  "building_person_px": 215,
  "assets": [
    { "file": "ground/G02_forest_a.png", "type": "ground", "id": "G02", "variant": "a", "size": [1024,1024], "seamless": true, "season": "summer" },
    { "file": "ground/L01_lavalake.png", "type": "landground", "id": "L01", "world_size": [1150,620], "scale": 2 },
    { "file": "beasts/redwolf_idle.png", "type": "beast", "id": "redwolf", "pose": "idle", "person_px": 320, "anchor": [340,370], "facing": "right" },
    { "file": "beasts/hawk_idle.png", "type": "beast", "id": "hawk", "pose": "idle", "person_px": 320, "anchor": [300,500], "facing": "right", "flying": true },
    { "file": "buildings/B17_inn.png", "type": "building", "id": "B17", "person_px": 215, "anchor": [700,960], "door_height_px": 320, "footprint": [40,700,1320,260], "door": [700,860] },
    { "file": "buildings/B13_sectwall.png", "type": "building", "id": "B13", "person_px": 215, "anchor": [512,420], "footprint": [0,360,1024,60], "tileable_x": true },
    { "file": "artifacts/art_qingzhu.png", "type": "artifact", "id": "art_qingzhu", "orient": "right" },
    { "file": "vfx/fx_fireball.png", "type": "vfx", "id": "fx_fireball", "frame": [256,256], "cols": 8, "frames": 12, "fps": 24, "loop": true, "blend": "add", "anchor": [128,128], "orient": "right" },
    { "file": "icon/herb_huangjing.png", "type": "icon", "id": "herb_huangjing" }
  ]
}
```

**字段说明：**

| 字段 | 含义 |
|---|---|
| `anchor` | 落地点（像素）。建筑：正面中轴与地面接触点；妖兽：四足中心的地面投影；飞行物：身体中心正下方的地面点 |
| `footprint` | 建筑、物件实际占地的矩形 `[x, y, w, h]`，用于碰撞 |
| `door` | 门洞中心点，可穿过的建筑才写 |
| `tileable_x` | 左右可无缝拼接 |
| `flying` / `water` | 飞行 / 水中 |
| `season` | `spring` / `summer` / `autumn` / `winter`，不分季节的不写 |
| `world_size`、`scale` | 名地大贴片的世界尺寸与交付倍率 |
| `frame`、`cols`、`frames`、`fps`、`loop`、`blend`、`orient` | 特效序列帧参数（见 G0） |
