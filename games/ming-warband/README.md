# 铁血大明 · 明末群雄（v1.4）

一款以 **崇祯八年（1635）** 明末乱世为背景的 2D 网页策略角色扮演游戏，玩法致敬《骑马与砍杀》：
在大地图上行军、招兵、经商、接任务，遭遇敌人后进入**即时战场**亲自冲杀，
一步步从无名小卒成长为一方诸侯，最终逐鹿天下。

> 技术栈：TypeScript + Vite + Phaser 3（地图/战斗渲染）+ 原生 DOM（界面）。
> 人物、地图与战场美术全部由代码程序化绘制（主菜单背景为 AI 生成的工笔水墨画），不使用任何第三方游戏素材。
> 所有音效与配乐都由 Web Audio 实时合成，没有任何音频文件。

## v1.4 更新：活的历史、国策 AI、千人战场

**历史跟着局势走，不再按日历硬触发**
- 每个大势力都有“国策”大脑，每隔几天重新评估局势：
  - **明廷兵部**把 20 位将领分派到五大战区（蓟辽、宣大九边、京营、中原、湖广四川），哪里吃紧就发“兵部急檄”调兵。
  - **大清**只有在八旗兵力压过九边守军、且开局五十日之后，才会挑长城上守备最薄弱的一段拆墙入塞；破墙后劫掠十四日再满载北返。
  - **闯营**随饥荒壮大，兵力够强时才会聚众东进、兵临北京。
- 大事都是局势的结果，例如：
  - **松锦大战**：清强、辽东明军弱时才会爆发，锦州可能失守，也可能解围。
  - **迎闯王**：在中原大旱或官军被抽调北上时触发。
  - **甲申之变**：北京真的陷落后才发生。
  - **吴三桂**：会给你修书劝说的机会；你自己镇守的山海关永远不会被献出。
- 各势力有不同的“国力”：明廷财政逐年崩坏、补兵越来越难；八旗兵源稳定；闯营随饥荒越打越多。
- 势力灭亡一段时间后，余部可能在故地复起，天下不会只剩你一支人马。

**长城更难过了**
- 十座关隘开局全归大明；关门只对本方军队打开。
- 关隘守军更强，攻打要有攻城器械、人数要够。
- 缺口会每日自动修补。
- 入塞时日志写明是“经由某关”，还是“从某处边墙破口”入塞。

**修复**
- 修复了玩三小时后世界只剩自己一支部队的问题。原因是一个卡住的守城提示，导致每日结算（领主重生、刷兵）停摆。
- 每个后台子系统都加了保护，出错不再拖垮整个世界。菜单里新增“错误报告”，可以一键复制。
- 修复了山海关因松锦事件突然变成清朝的问题。

**战场与画面**
- 战场同屏上限 1000 人（敌我合计），可在“战场设置”里改为 300/600/1000；新增最大一档战场。性能优化后千人混战依然流畅。
- 大地图上的长城重画为高清版：墙体立面带垛口，敌楼与楼阁连绵，墙外设烽火台。
- 关隘是骑墙而建的多层关楼，山海关、嘉峪关、居庸关更加雄伟。
- 城镇和城堡有了多种样式：鼓楼、宝塔、文庙、营房校场。
- 界面图标改为统一的手绘线描（不再依赖系统 emoji），面板底部点缀淡墨远山。

## v1.3 更新：长城、合军、大战场、明末大事

**万里长城真正挡住关外之敌**
- 长城是实打实的屏障：关外的八旗、蒙古不能随意越过，只能走 **10 座关隘**（山海关、喜峰口、古北口、居庸关、张家口、杀虎口、偏头关、榆林、花马池、嘉峪关）。
- 关隘归谁所有，谁就能放行；敌对势力必须先**攻破关隘**，或者集结大军**拆毁边墙**、打开缺口。
- 边墙被破会**点燃烽火**，消息一路传开；守关势力可以出资**修缮边墙**（关隘菜单）。
- 小股人马可以**趁夜偷越**边墙，白天则会被守军挡住；持有关隘的一方每周还能收**关税**。

**合军与大会战**
- 领主之间会合兵成军团；你可以邀请领主"随我出征"，统领最多四路兵马。
- 战斗中友军、敌方援军一并入场，战场按兵力自动放大。
- HUD 上 🚩 显示随行军团，点击可遣散。
- 攻城战可以准备云梯、冲车、火炮、地道；守城战会提示你入城助守。

**历史大事（一日即一旬，36 天为一年）**
- 从崇祯八年（1635）凤阳之变起，依次有：大清建号、三次清军入塞、闯王被擒、谷城受抚与复叛、迎闯王、洛阳陷落、松锦大战、洪承畴降清、皇太极猝死、大顺建国、兵临北京、山海关之战、张献忠入川……
- **历史会随局势改写**：锦州守住了，洪承畴就不会降；北京守住了，吴三桂就不会开关。你可以亲手改变明朝的命运。
- 大事以史书卷轴弹出，"天下（F）"面板里有大事记，还会提示坊间传闻。
- 势力会改名：后金→大清、闯军→大顺、西营→大西，北京陷落后大明→南明。
- 随机事件：旱灾、蝗灾、瘟疫、丰收、豪杰来投、饥民投闯。

**其他**
- 城镇新增 🏹 **武举校场**：五轮比武，可以押注，全胜者被钦点为"武状元"。
- 都城与关隘守军更多、补充更快（北京、山海关是真正的坚城）。

## v1.2 更新：声音、天气与细节

- **声音（全部由代码实时合成）**：古筝、笛、琵琶风格的五声音阶配乐（主菜单 / 大地图白天 / 夜晚 / 野战 / 攻城各一套，
  战斗越激烈鼓点越密）；刀剑相击、甲片、弓弦、弩机、火铳、火炮、战马、呐喊、号角、战鼓、锣、钱币、翻页等 30 多种音效，
  按距离与左右声像混音；环境音有鸟鸣、虫鸣、风声、雨声、雷声、战场喧嚣与马蹄。按 **M** 静音，菜单里有「声音设置」可分别调节音量。
- **天气与季节**：按地域与季节变化——江南梅雨、北方冬雪、西北干燥；有小雨/大雨/雷雨（闪电+雷声）与小雪/大雪。
  冬天北方大地会积雪；春有飞花、秋有落叶、夏夜有萤火。战斗会沿用当时当地的天气：雪地战场、雨后泥泞水洼。
- **大地图细节**：村镇周围有成片的农田（北方麦田垄沟、南方水田、丘陵梯田）、农舍、草垛、田边树；
  河流有河滩与波光，官道过河处架有石桥；长城带垛口与敌楼；江上有乌篷船与帆船，沿海有福船，天上有雁阵；
  饭点村里升起炊烟；入夜城镇村庄亮起灯火，主角队伍举着火把。
- **夜战**：部分士兵举着火把，两军阵后燃起篝火、火星飞溅；攻城夜战城头挂灯。
- **战斗细节**：刀剑格挡、砍中重甲会迸出火花；开战时有「战 / 夜 / 攻」大字开场。
- **界面**：左上角日晷小窗（天色、日月、雨雪随时辰变化）+ 季节印章 + 天气；进入城镇/关城/村庄时顶部有水墨横幅
  （随时辰、季节、天气、战火变化，每个地方都不一样）；右上角新增小地图，可点击跳转。

## v1.1 更新：画面大翻新

## 怎么玩

| 方式 | 说明 |
| --- | --- |
| **单文件版（最简单）** | 运行 `npm run build:single`，再双击打开 `dist-single/铁血大明.html` |
| 开发模式 | `npm install && npm run dev`，浏览器打开 `http://localhost:5173` |

存档保存在浏览器的 localStorage 中（1 个自动存档 + 3 个手动存档）。

## 内容一览

**大地图**
- 按真实经纬度绘制的明末中国舆图：海岸线、黄河（1635 年夺淮入海的古河道）、长江、珠江、汉水、长城与辽东边墙
- 8 种地形（平原、草原、森林、丘陵、山地、荒漠、高原、海），影响行军速度，A* 寻路
- 昼夜交替（夜间视野缩小、行军变慢），战争迷雾（侦察技能决定视野）
- 23 座城镇、26 座城堡、70 余座村庄

**势力与 AI**
- 五大势力：大明、后金、闯军（李自成）、西营（张献忠）、察哈尔（林丹汗），共 34 位历史领主
- 领主 AI 会招兵、巡逻、追击、逃跑、劫掠村庄、围攻城池、救援友军
- 势力之间会宣战与议和，城池会易手，势力会灭亡
- 山贼、倭寇、马贼、流寇按地域刷新；商队与乡民往来于城镇之间

**即时战斗**
- 亲自上阵：WASD 移动，鼠标瞄准，左键攻击，Q 切换近战/远程
- 骑马冲撞伤害加成、长枪克骑、弓弩铳的射程与装填差异、鸟铳破甲
- 编组指挥（1-4 选择，Z 冲锋 / X 坚守 / C 跟随），士气与溃逃，分批援军
- 攻城战：城墙、破损的城门、垛口后的守军弓手
- 随时可以用自动结算完成战斗，也可以撤退

**角色与部队**
- 5 种出身，4 项属性，12 项技能（铁骨、强击、射术、骑术、统御、训练、战术、交易、医术、侦察、寻路、管束）
- 50 余种兵种，每个势力都有自己的兵种树（戚家军、白杆兵、关宁铁骑、神机营、巴牙喇、怯薛……）
- 兵员积累经验后可以晋升；伤兵、军饷、粮食、士气、逃兵
- 10 位可招揽的同伴，各有专长（同伴技能视为队伍技能）
- 30 余件装备：雁翎刀、苗刀、偃月刀、角弓、鸟铳、布面甲、山文甲、蒙古马、大宛良驹……

**经济与成长**
- 12 种商品，各城有特产和紧缺货物，价格随供需波动
- 俘虏：卖给牙人，或者招降
- 任务：剿匪、送信、运粮、补充守军
- 雇佣兵契约（声望 30）→ 宣誓效忠成为封臣并获得封地（声望 120）→ 攻城略地
- 也可以自立门户，最终目标是夺取天下所有城镇

## 代码结构

```
src/
  data/      兵种、装备与商品、势力/城镇/领主/同伴等静态数据
  core/      游戏逻辑（与渲染无关，可在 Node 中运行）
    terrain.ts   地形生成、地图绘制、A* 寻路
    game.ts      全局状态、新游戏生成、势力关系
    sim.ts       大地图模拟：时间、移动、AI、每日/每周结算
    strategy.ts  国策 AI：明廷五大战区、清军择弱入塞、闯营进京
    calendar.ts  由局势触发的明末大事、随机事件、势力复起
    wall.ts      长城、关隘与缺口
    combat.ts    自动结算、战后处理、攻城与占领
    economy.ts   价格与贸易
    quests.ts    任务
    character.ts 属性技能与派生数值
    party.ts     部队工具函数
    save.ts      存读档
    weather.ts   天气与季节（按地域、时间确定性生成）
  art/       程序化美术：人物精灵表（figures/specs）、地图装饰与建筑（mapArt/worldBuild）、
             战场地面与道具（battleArt）、Phaser 纹理缓存（phaserTex）、界面立绘（portrait）
  audio/     Web Audio 合成：engine（总线/混响/设置）、sfx（音效配方）、music（配乐与环境音）、hooks（与游戏事件挂接）
  assets/    主菜单背景图
  scenes/    Phaser 场景：WorldScene（大地图）、BattleScene（即时战斗）
  ui/        DOM 界面：HUD、据点菜单、遭遇、各类面板、主菜单
```
