# 铁血大明 · 明末群雄（v1.0）

一款以 **崇祯八年（1635）** 明末乱世为背景的 2D 网页策略角色扮演游戏，玩法致敬《骑马与砍杀》：
在大地图上行军、招兵、经商、接任务，遭遇敌人后进入**即时战场**亲自冲杀，
一步步从无名小卒成长为一方诸侯，最终逐鹿天下。

> 技术栈：TypeScript + Vite + Phaser 3（地图/战斗渲染）+ 原生 DOM（界面）。
> 美术全部由代码绘制，不使用任何第三方游戏素材。

## 怎么玩

| 方式 | 说明 |
| --- | --- |
| **单文件版（最简单）** | 运行 `npm run build:single`，再双击打开 `dist-single/铁血大明.html` |
| 开发模式 | `npm install && npm run dev`，浏览器打开 `http://localhost:5173` |
| 发布版 | `npm run build`，把 `dist/` 放到任意静态服务器（如 `npx serve dist`） |

存档保存在浏览器的 localStorage 中（1 个自动存档 + 3 个手动存档）。

## 内容一览

**大地图**
- 按真实经纬度绘制的明末中国舆图：海岸线、黄河（1635 年夺淮入海的古河道）、长江、珠江、汉水、长城与辽东边墙
- 8 种地形（平原、草原、森林、丘陵、山地、荒漠、高原、海），影响行军速度，A* 寻路
- 昼夜交替（夜间视野缩小、行军变慢），战争迷雾（侦察技能决定视野）
- 23 座城镇、26 座城堡、70 余座村庄

**势力与 AI**
- 五大势力：大明、后金、闯军（李自成）、西营（张献忠）、察哈尔（林丹汗），共 34 位历史领主
- 领主 AI 会招兵、巡逻、追击、逃跑、劫掠村庄、围攻城池、救援友军
- 势力之间会宣战与议和，城池会易手，势力会灭亡
- 山贼、倭寇、马贼、流寇按地域刷新；商队与乡民往来于城镇之间

**即时战斗**
- 亲自上阵：WASD 移动，鼠标瞄准，左键攻击，Q 切换近战/远程
- 骑马冲撞伤害加成、长枪克骑、弓弩铳的射程与装填差异、鸟铳破甲
- 编组指挥（1-4 选择，Z 冲锋 / X 坚守 / C 跟随），士气与溃逃，分批援军
- 攻城战：城墙、破损的城门、垛口后的守军弓手
- 随时可以用自动结算完成战斗，也可以撤退

**角色与部队**
- 5 种出身，4 项属性，12 项技能（铁骨、强击、射术、骑术、统御、训练、战术、交易、医术、侦察、寻路、管束）
- 50 余种兵种，每个势力都有自己的兵种树（戚家军、白杆兵、关宁铁骑、神机营、巴牙喇、怯薛……）
- 兵员积累经验后可以晋升；伤兵、军饷、粮食、士气、逃兵
- 10 位可招揽的同伴，各有专长（同伴技能视为队伍技能）
- 30 余件装备：雁翎刀、苗刀、偃月刀、角弓、鸟铳、布面甲、山文甲、蒙古马、大宛良驹……

**经济与成长**
- 12 种商品，各城有特产和紧缺货物，价格随供需波动
- 俘虏：卖给牙人，或者招降
- 任务：剿匪、送信、运粮、补充守军
- 雇佣兵契约（声望 30）→ 宣誓效忠成为封臣并获得封地（声望 120）→ 攻城略地
- 也可以自立门户，最终目标是夺取天下所有城镇

## 操作速查

| 场景 | 按键 |
| --- | --- |
| 大地图 | 左键 行军/进入/追击；拖动或 WASD 平移；滚轮缩放；空格 扎营等待；1/2/3 速度；H 回到自己位置 |
| 面板 | C 角色　P 部队　I 行囊　F 天下大势　Q 任务　L 日志　Esc 菜单/关闭 |
| 战斗 | WASD 移动；左键 攻击；Q 换武器；1 全军 2 步兵 3 远程 4 骑兵；Z 冲锋 X 坚守 C 跟随 |

## 代码结构

```
src/
  data/      兵种、装备与商品、势力/城镇/领主/同伴等静态数据
  core/      游戏逻辑（与渲染无关，可在 Node 中运行）
    terrain.ts   地形生成、地图绘制、A* 寻路
    game.ts      全局状态、新游戏生成、势力关系
    sim.ts       大地图模拟：时间、移动、AI、每日/每周结算
    combat.ts    自动结算、战后处理、攻城与占领
    economy.ts   价格与贸易
    quests.ts    任务
    character.ts 属性技能与派生数值
    party.ts     部队工具函数
    save.ts      存读档
  scenes/    Phaser 场景：WorldScene（大地图）、BattleScene（即时战斗）
  ui/        DOM 界面：HUD、据点菜单、遭遇、各类面板、主菜单
```

## 说明

本作是架空演义，部分人物、势力与地盘为了游戏性做了调整，并不完全符合史实。
