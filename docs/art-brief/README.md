## 0. 一句话任务

为一款**水墨淡彩风**的 2D 俯视修仙游戏，画出**风格统一**的第一批美术样品，推送到 GitHub 的指定分支：
1. **地面贴图**：无缝平铺。
2. **建筑**：透明底立绘。
3. **妖兽**：透明底立绘。

**这一轮只做样品，不做全量。** 样品会被接进游戏、截图、交给负责人确认风格。风格确认后才进入批量生产（第 2 轮以后，见附录）。

## 1. 背景：项目是什么

- **仓库：** `https://github.com/qwasx/win-mcp-bridge`
- **游戏目录：** `fanren/`
- **最新代码所在分支：** `arena/01a0db51-win-mcp-bridge`
- **技术栈：** TypeScript + Vite + Canvas2D/WebGL。
  - 地面由 WebGL 着色器绘制。
  - 建筑、妖兽、人物是 2D 精灵，按 y 坐标排序叠放。
- **题材：** 忘语《凡人修仙传》同人。
  - 开放大世界，有天南、乱星海、大晋三张地图。
  - 主角韩立从黄枫谷炼气期开始修炼。
- **镜头：** 俯视偏正面（类似 RPG Maker / 星露谷的「正面俯视」）。
  - 地面是正上方看下去的。
  - 山、树、房子、人物都是「正面略带俯视」的立绘，**没有 45° 斜角（等距）视角**。

## 3. 全局美术规范（所有素材都必须遵守）

### 3.1 画风

**水墨淡彩（工笔淡彩 / 小青绿）。**
- 淡墨勾线：线有粗细、有顿挫，**不要矢量等宽线**。
- 淡彩罩染：颜色薄，能透出底色。
- 微微的宣纸纹理。

**参照：**
- 色彩：王希孟《千里江山图》（青绿、赭石）。
- 建筑画法：宋代界画，如《黄鹤楼图》《滕王阁图》，用平行透视，规整而有笔意。
- 质感：游戏《鬼谷八荒》大地图、《江湖悠悠》、《墨剑江湖》的水墨感（只借鉴感觉，不要照抄）。

**禁止：**
- 照片写实、3D 渲染感、塑料感、厚涂油画感、高光反射。
- 卡通 / Q 版、日式赛璐璐、矢量扁平（Flash 游戏感，也就是现在妖兽的问题）。
- 高饱和颜色、纯黑描边、霓虹色。

### 3.2 视角（非常关键）

| 素材类型 | 视角 |
|---|---|
| **地面贴图** | **正上方垂直俯视**（正交），没有透视、没有地平线，不能出现任何「立起来」的东西。 |
| **建筑** | **正面 + 俯视约 30°，平行投影**（界画式）：正立面完整可见，屋顶坡面也可见，没有灭点，左右对称的建筑就画成对称。**不要转成 45° 斜角。** 侧墙可以露一点点厚度，但正面必须平行于画面。 |
| **妖兽** | **侧面 + 俯视约 20°**，**头朝右**（朝左由程序翻转）。四条腿要都能看到或能读出来。飞行类画成展翅的侧面略俯视。 |

### 3.3 光照

- 统一**左上方**柔和来光。
- 明暗对比低，只用淡墨分出体积。
- 不要强烈的投影。

**投影规则：**
- **建筑和妖兽不要画落在地面上的投影**，程序会加。
- 建筑自带的台基、台阶属于建筑本身，要画。
- 底部接地处可以有很淡的接触阴影（AO），宽度不超过 10 px。

### 3.4 配色（取自游戏里的山，是画风锚点）

| 用途 | 色值 |
|---|---|
| 青绿山顶 | `#2f6470` |
| 青绿山腰 | `#5d9478` |
| 山脚赭石 | `#cdb98e` |
| 淡墨 | `#1f2a28` |
| 远山灰蓝 | `#9fb5b8` |
| 苔绿 | `#1d3a2c` |
| 宣纸底 | `#e9dfc6` |
| 屋瓦灰 | 约 `#7d8288` |
| 朱漆 | 约 `#a8432f`（用于柱、门） |

- **地面的明度要比建筑、人物低半档、饱和度低一档**，让人和房子从地面上「跳出来」。
- 地面是衬底，不要抢戏。

### 3.5 比例尺（所有素材以人为准）

- 参照图 `scale-person-215px.png`：**一个成年人 = 215 px 高**。我们称之为「2 倍比例」，游戏里的人约 108 世界像素高。
- 建筑和妖兽**按 2 倍比例或更大**绘制（3 倍更好，细节更足），并在 `manifest.json` 里写明该图里「一个人有多高」（`person_px`），程序会缩放。
- **门高 ≈ 1.4～1.6 个人高。** 这是检查建筑比例最直观的一条。
  - 现在游戏的问题之一就是房子太小、人太大（见 `04`、`06`）。
  - 新建筑要按真实比例画，程序会把城镇布局放大。

### 3.6 文件技术要求

- **格式：**
  - 地面贴图：PNG（24 位即可）。
  - 立绘：PNG 32 位 RGBA，直通 alpha，不要预乘。
  - 颜色空间 sRGB。
- **抠图要求：**
  - 边缘抗锯齿、干净，**不能有白边、色边**，**不能把棋盘格背景画进去**。
  - 半透明部分（烟、水汽、鬼魂）保留真实 alpha。
- **不能出现：** 任何文字、签名、水印、边框。
  - 匾额、招牌、旗帜**留白**（程序会写字）。
  - 也不能出现 AI 生成的乱码字。
- **AI 常见瑕疵要修掉：**
  - 屋檐、斗拱融化、扭曲，左右不对称的「对称建筑」。
  - 多腿、少腿，五官错乱。
  - 栏杆、窗格断裂。
- **建议工作法：**
  1. 先做一张「风格定调图」（style key）。
  2. 之后所有素材都用它做风格参考或垫图（img2img、IP-Adapter、风格参考等，你有什么用什么），保证统一。
  3. 高分辨率生成，再缩小交付。

## 4. 第 1 轮交付清单（样品）

### 4.1 地面贴图（第一优先）

**目标：** 精致的水墨地面，远看是一片有呼吸感的淡彩，近看有笔触和细节。

**要有：**
- 淡彩底：颜色有轻微的浓淡起伏，像水彩在宣纸上晕开。
- 偶尔的水渍边缘。
- 稀疏的**干笔飞白**：草地上顺着一个方向扫过的笔触。
- 国画里的**点苔**：小墨点、色点。
- 小碎石、草叶等细节。

**不要：**
- 照片纹理。
- 均匀的高频噪声：现在的问题就是这种噪声，像绒布、像杂色。
- 大块明显的单个物体：平铺后会一眼看出重复。

#### 规格

- **1024 × 1024 px**，**上下左右四边无缝**。
  - 自检：把同一张拼成 3×3，看不出接缝、看不出明显重复的「图案中心」。
- **细节尺度**（以 215 px 的人为准）：
  - 一块贴图在游戏里约等于 4.7 个人身高见方。
  - 小石子 8～25 px，草丛 25～60 px，单根草叶笔触 10～40 px 长。
- 同一材质的几张**变体**之间：色调、明度一致，只是细节分布不同。程序会在大地图上随机混用，并用噪声在材质之间过渡。

#### 本轮要做

| 编号 | 名称 | 数量 | 说明 |
|---|---|---|---|
| G01 | 草地（越国温带，春夏） | 2 张变体 | 主力地面，占大地图 60% 以上。青绿偏黄的淡彩底，干笔草痕、点苔、零星小花点（极少） |
| G04 | 土路 / 小径地面 | 1 | 赭石淡彩、夯土质感、少量车辙和脚印的淡墨痕。程序会把它沿道路形状铺开，和草地融合 |
| G06 | 碎石 / 山脚乱石地 | 1 | 灰赭底，大小碎石用淡墨勾、淡彩染，石缝里有少量草 |
| G15 | 城镇青石板地面 | 1 | 规整而不死板的石板，缝里有苔，石面有淡淡的磨损和水渍。石板大小约 0.8～1.2 个人高 |

**另做点缀贴片（透明 PNG，不需要无缝），共 6 个：**

| 编号 | 名称 | 尺寸建议 | 说明 |
|---|---|---|---|

### 4.2 建筑（第二优先）

#### 现有建筑贴图哪里不对（看 `04`、`05`、`06`、`08`）

1. **像建筑效果图 / CG 渲染**，干净、硬，没有笔意，和水墨山放在一起格格不入。
2. **比例错误**：人有半个大殿高。新建筑请严格按「门高 ≈ 1.5 人」画。
3. **太单一**：整个宗门是同一座殿复制五次，靠调色区分，越调越脏。
4. **不接地**：房子像贴纸一样浮在地面上。新建筑要带**台基、台阶、墙根的苔痕、檐下的阴影、门前的石阶或石狮、几丛小草**，让它「长」在地上。
   - 注意：**不画落地投影**。

#### 规格

- 正面俯视 30° 平行投影（见 3.2），透明背景。
- 交付时在 manifest 里给出**锚点**：建筑正面中轴线和地面接触的那个点的像素坐标，一般是最下面一级台阶的前沿中点。
- 尺寸参考（2 倍比例，人 = 215 px）：

| 编号 | 名称 | 宽度参考 | 说明 |
|---|---|---|---|
| B01 | **宗门主殿**（越国正道宗门，以黄枫谷为准） | 1600～2000 px | 重檐歇山顶，灰瓦（可以有少量黄绿琉璃剪边），朱红柱、门窗，汉白玉台基，三出台阶，两侧可有铜鼎、灯幢。庄重、仙气，不要皇宫那种金碧辉煌 |
| B02 | **越国民居** | 800～1000 px | 一层或一层半，悬山顶灰瓦，白墙木构，木门、直棂窗，墙根青砖，屋旁可有柴堆或水缸。朴素、有人味 |
| B03 | **坊市店铺**（两层） | 900～1100 px | 二层木楼，一楼敞开的柜台门面（可以看到一点货架、药柜轮廓），**空白招牌**和**空白幌子**，屋檐挂灯笼 |
| B04 | **宗门山门** | 1200～1500 px | 石牌楼式或门楼式均可（二选一，在说明里写明选择）。石构为主，**匾额留白**，两侧可有石狮或石灯 |

- 有余力再加一张 **B05 城墙段**：可水平无缝拼接的一段城墙正面，高约 3 个人，带垛口，宽 1024 px，左右边缘能接上。

**风格要点：**
- 宋代界画的规整，加上淡墨淡彩的笔意。
- 瓦垄用淡墨线排出节奏，不要逐片渲染瓦片。
- 木构的朱红要沉稳，不要鲜红。
- 白墙要带一点宣纸黄。

**还要 1 张建筑示意图**（`mockup_buildings.png`，2560×1600）：
- 在 4.1 的地面贴图上，摆一个小街角：店铺、两栋民居，远处一座主殿。
- 放 2～3 个 `scale-person-215px.png` 的人。
- 按游戏的俯视规则：越靠下越近、遮挡在前。

### 4.3 妖兽（第三优先）

#### 现有妖兽为什么难看（看 `07`）

- 矢量扁平、塑料感、像儿童绘本或 Flash 小游戏。
- 解剖结构不对，没有威胁感，和水墨世界不搭。

#### 新妖兽要求

- **水墨淡彩**，像国画里的走兽、《山海经》插图那样：
  - 用淡墨写意的笔触表现毛、鳞、甲。
  - 有重量感，有凶性，有灵气。
  - 每种妖兽有一处醒目的「灵异特征」（火焰、第三只眼、冰甲……），用淡彩、微光表现。
- **侧面、头朝右、俯视约 20°。** 透明背景。不画落地投影。
- **每只交 2 个姿态：**
  - **待机 / 行走**（四足动物画一侧前腿迈出的姿态）。
  - **扑击 / 攻击**（前扑、张口、举爪）。
- **两张图里的身体比例、配色、细节必须完全一致**，只改姿态。动作由程序用这两张图加形变来驱动。
- 尺寸：按 2 倍比例画，并写 `person_px`。体型参考附录 B 的「身长（人高倍数）」，最长边至少 600 px。

#### 本轮要做

| 编号 | 名称 | 体型 | 原著 / 设定特征 |
|---|---|---|---|
| M01 | **青背苍狼**（一级，最常见） | 身长约 1.1 人 | 瘦长的灰狼，**背脊一道青黑色鬃毛**，眼睛泛幽绿。普通妖兽的基准，要「真实的狼」加一点点妖异 |
| M02 | **火蟾兽**（坠魔谷，四～六级） | 身长约 1.8 人，高约 1 人 | 巨大的赤褐色蟾蜍，背上**熔岩般的疙瘩和裂纹**透出橘红色的光，嘴角冒火星，喉囊鼓起。生活在火山熔岩湖边 |
| M03 | **墨蛟**（血色禁地妖王） | 身长约 6 人 | 由黑鳞蟒蜕变而成的蛟：**通体墨黑鳞片**，头上有两个肉角初生的鼓包，四只短爪，身体修长蜿蜒，口吐**墨绿腐水和紫色毒雾**。待机是盘曲抬头，攻击是张口喷吐 |

- 可选加一只 **M04 阴魂**（鬼物）：半透明的苍白人形残影，下半身化作烟缕。用来测试半透明画法，alpha 要真实。

### 5.2 `manifest.json` 格式

```json
{
  "round": 1,
  "assets": [
    { "file": "ground/G01_grass_a.png", "type": "ground", "id": "G01", "variant": "a", "size": [1024, 1024], "seamless": true },
    { "file": "ground/D01_grasstuft.png", "type": "decal", "id": "D01" },
    { "file": "buildings/B01_sect_hall.png", "type": "building", "id": "B01", "person_px": 215,
      "anchor": [1010, 1288], "door_height_px": 320, "symmetric": true },
    { "file": "beasts/M01_wolf_idle.png", "type": "beast", "id": "M01", "pose": "idle", "person_px": 215,
      "anchor": [300, 410], "facing": "right" }
  ]
}
```

- `anchor`：落地点像素坐标。
  - 建筑：正面中轴线与地面的接触点。
  - 妖兽：四足中心在地面上的投影点。
  - 飞行类：身体中心正下方的地面点，并加 `"flying": true`。
- `person_px`：这张图的比例下一个人有多高（2 倍比例就是 215）。
