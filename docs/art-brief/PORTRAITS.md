**新画的每一张，和这 9 张并排放，要看不出是两个人画的。** 动手前先把这 9 张都打开看一遍。尤其是**男性角色，以 `hanli.webp` 为准**。

### 1.1 这 9 张的共同特征（照做）

| 项目 | 要求 |
|---|---|
| 画风 | 国风淡彩工笔插画：墨色细线勾勒，水彩薄涂、柔和晕染，衣纹精细，饰品有细节 |
| 构图 | **半身像**：头顶到腰胯，人物居中略偏，正面或 3/4 侧身。头顶离画面上沿约 8%–12%，脸在画面上三分之一 |
| 人物占比 | 人物宽度约占画面 60%–75%，左右两边留出背景 |
| 手 | **双手或单手在胸腹前，拿着这个人的标志物**（法宝、兵器、扇、笛、丹瓶、书……）。标志物可以带一层淡淡的灵光 |
| 背景 | **米黄色宣纸底**，加很淡的水墨远景：竹、松、梅枝、柳、祥云、远山、圆月……只用淡墨和一点点淡彩，**绝不能抢人物** |
| 光 | 柔和的正面光，没有强烈的明暗对比，没有黑底 |
| 比例 | 写实比例，**修长，七头身的上半身**。头不大，脖子、肩膀正常 |
| 脸 | 清秀、端正，眼睛不夸张 |

### 1.2 禁止

- Q 版、卡通、大头、日式萌系大眼、厚涂、3D 渲染感、照片感。
- 黑色或深色背景、纯色背景、渐变背景。
- 画框、边框、文字、签名、印章、水印、Logo。
- 暴露、性感的姿势和服装。魔道女修可以妖艳，但衣着要得体。
- 血腥、断肢。魔头可以阴森，但不要恐怖片风格。
- 手指畸形、多手指、手里的东西和手不衔接。**每张都要检查手。**

### 1.3 男性角色特别注意

现有样张大多是女性。男性角色**不能**画成一模一样的「白净美男」。要做到：

- **按年龄分开**：少年、青年、中年、老年，脸型、皱纹、胡须都要不同。老年人要有真实的老态：白发、皱纹、眼袋、瘦削或发福。
- **按身材分开**：瘦弱、精干、魁梧、肥胖都要有。
- **按气质分开**：正道温和、冷峻、憨厚；魔道阴鸷、狂傲、狡诈；散修风霜、寒酸、凶悍。
- 魔道、劫修的凶相靠**眼神、眉形、胡须、伤疤、服色、背景色调**体现，画风本身不变。

## 3. 交付方式

### 3.1 分支与目录

- **分支：`art/portraits`**，从 `origin/arena/01a0db51-win-mcp-bridge` 切出。**只新增文件，不修改任何现有文件。**

```
git fetch origin arena/01a0db51-win-mcp-bridge
git checkout -b art/portraits origin/arena/01a0db51-win-mcp-bridge
```

- **目录：**

```
fanren/art-incoming/portraits/
  named/      npc_<id>.png        专属立绘，<id> 见第 4 节表格第一列
  generic/    gen_<id>.png        通用立绘池，<id> 见第 5 节表格第一列
  sheets/     sheet_<组名>.jpg     每组一张缩略拼图（见 3.3）
  manifest.json
  NOTES.md
```

### 3.2 manifest.json

每推送一批就把新文件追加进去：

```json
{
  "version": "portraits",
  "size": [1080, 1440],
  "assets": [
    { "file": "named/npc_lihuayuan.png", "type": "named", "id": "lihuayuan", "name": "李化元", "sex": "m", "age_look": 50, "faction": "sect", "sect": "huangfeng" },
    { "file": "generic/gen_sect_m1.png", "type": "generic", "id": "sect_m1", "sex": "m", "age_look": 22, "faction": "sect", "role": "cultivator" }
  ]
}
```

- `age_look`：画出来**看上去**的年龄（修仙者外貌年龄可能和真实年龄不同，以表格「外貌」一栏为准）。
- `faction`：`sect` / `demon` / `rogue` / `mortal` / `merchant` / `monk` / `beast`。
- `role`（通用池才写）：`cultivator` / `elder` / `female` / `farmer` / `scholar` / `merchant` / `guard` / `monk` / `child`。

### 3.3 缩略拼图

每推送一组，同时交一张该组的缩略拼图 `sheets/sheet_<组名>.jpg`：每张缩成 270×360，一行 6 张。**拼图里第一张固定放 `hanli.webp` 作对照。** 负责人会看拼图来验收整体是否统一。

### 3.4 顺序与节奏

1. **先画第 4.1 组（黄枫谷，8 张）**，推送一次。
2. 然后按第 4 节表格顺序往下画，**每完成一组（或约 20 张）推送一次**，不要攒到最后。
3. 最后画第 5 节通用立绘池。
4. 不需要等验收，一直往下做。每次推送之前，看一下仓库里有没有 `docs/art-brief/FEEDBACK_PORTRAITS.md`，有新内容就先改。
5. 表格「优先级」一栏：**A** = 主线常见，必须画；**B** = 也要画，排在 A 后面。
