# s3-world · 第 3 阶段：活世界的地基

## 一句话
NPC 不再围着玩家转：每个人都有储物袋、本命法宝、功法和名声，按自己的需要定目标、真的在地图上赶路，撞上了就按战力分胜负，东西真的换主人；世上发生的事记成传闻，按 **I** 打开「风云录」能看到传闻栏和风云榜。

## 改动（像 README 那样分条）
- **修士一视同仁**（`src/world/sim/kit.ts`）
  - NPC 新增字段（旧存档缺省时自动补）：`bag` 储物袋（与 `Hero.bag` 同结构）、`main` 本命法宝、`gongfa` 功法、`xp` 本小境界进度、`fame` 名声、`aim` 当前目标。灵石仍记在 `wealth`。
  - 配装 `outfit(d)`：按「地域（market 的流通分区）× 宗门（本门秘传、剑派偏飞剑、魔门偏阴血法器）× 境界」配法器、修为丹、疗伤丹、符箓、灵草妖丹；行商带货；原著人物带成名法宝（`NpcWorld.TREASURE`）。种子确定，同一人每次配出同一身行头。
  - 战力 `power()`：玩家和 NPC 同一个公式（境界气血×攻击 × 功法 × 本命法宝 × 随身法器 × 符箓）。风云榜、NPC 互斗、劫修挑肥羊都用它。
  - **打你时用的就是这些**：`sim/arm.ts` 的 `armEnemy()`——NPC 化为敌人时攻守按家当折算，招式里多一式「祭出·某某法宝」；斗法中血少时真的吃他储物袋里的疗伤丹（吃一颗少一颗）。
  - **死了掉的也正是这些**：`NpcWorld.dropLootOf(d, x, y)` = 生前整只储物袋 + 身上灵石（原来的随机功法 / 随机法器掉落已去掉）。成名法宝若生前已被人抢走，就掉不出来了。
- **需求 → 目标 → 行动**（`WorldSim.think`）
  - 寿元将尽（过八成四）→ 去秘境搏命（得延寿丹当场服下）；
  - 卡在大境界门槛又缺筑基丹 / 降尘丹 → 有钱去大城拍卖会买；买不起、性子贪狠的 → 盯上身怀此丹又打得过的人去抢，找不到就去路口拦路；其余去险地猎妖攒钱；
  - 有血仇（`vend` / 宿敌）→ 去追杀，目标一路跟着仇人跑；
  - 宗门弟子 → 接差事（去险地斩妖、回山交差，有望赏筑基丹）/ 回山闭关；行商 → 城与城之间跑货；劫修 → 守在两城之间的路口；散修 → 猎妖、寻宝、闭关、游历。
  - 定了目标就真的赶路（遁速按境界），不再瞬移；到了才办事。
- **三层模拟**
  - 神识之内：原有的完整行为（走、飞、打坐、斗法、交谈），到站时问 `sim.steer()` 该往哪去；
  - 同图其余的人：`sim.live()` 每帧实时赶路，每 0.5 秒网格分桶查一次谁撞上了谁 → `resolve()` 按战力出胜负，劫财 / 杀人夺宝 / 了结血仇，储物袋真的转手（`takeAll` / `takeSome`），符箓在斗法里真的用掉，遁地符能保命；
  - 其他地图：`sim.slow()` 分帧轮转（每帧几十人），按天推进同一套规则；一下子过去很多天（闭关、远行）时 `sim.daily(days)` 同步补完。
  - 新目录 `src/world/sim/`：`world.ts`（模拟本体，不碰画面）、`kit.ts`（家当与战力）、`arm.ts`（化敌武装）、`host.ts`（把 Game 接上来）、`witness.ts`（世界见证入口）。
- **事情由 NPC 之间自然发生**
  - `happen.ts` 不再在神识圈外凭空生成劫修、追杀；劫道就是劫修真的撞上了行商 / 弱者，在哪儿都可能发生。
  - 玩家在场（神识 1.4 倍内）：两人被拉进神识层，当着你的面斗法（`NpcWorld.showClash → startDuel`），结局按同一套规矩结算（`sim.settle`）。你仍可按 T 插手。
  - 恶名在外时的赏金客：从真人里挑一个贪财又自认打得过你的，动身来找你（`recruitBounty`），不再凭空出现。
  - 商队奇遇挂在真实的行商身上（`merchantNear` / `caravanEnd`）：护送成功他好感大增、照常做生意；被劫了，他本人真的丢了货和灵石。
  - 秘境 / 险地有宝藏池（`ws.sim.sites`），NPC 先到先得；你去晚了只剩空壳，会提示「X 年 X 月被某某取走」；还在的就落在你眼前。
- **NPC 真的会成长**（`WorldSim.grow`）
  - 修为 = 打坐（闭关 ×1.5）× 功法修炼速度；隔些日子吃一颗对路的修为丹；冲大境界有辅助丹药成算大增（筑基丹 65% / 无丹 15% …），失败退回一截再熬。散修元婴仍守名额（`demog.canAdvance`），迁徙也守。
  - 捡到宝、抢到宝立刻换上更好的本命法宝（`reequip`），战力跟着涨。
- **风云录（新 UI：`src/ui/WorldPanel.tsx`，快捷键 I；大事记「江湖传闻」栏也有按钮）**
  - 传闻栏：只列世上真实发生过的事；亲眼所见当场记下，不在场的按距离晚几天才传到（他图要一两个月）；可按「杀人夺宝 / 秘境机缘 / 突破异象 / 亲眼所见」筛。NPC 交谈、打听消息时也会说起你还没听说的事（说了就算听说了）。
  - 风云榜：三界 / 各图按战力排，你也在榜上；列出本命法宝和近闻。
- **世界地图众生往来**（`src/ui/simOverlay.ts`，接在 `Panels.tsx` 的世界地图里一行）：已探明地界里能看到修士的遁光往来，颜色 = 在干嘛，赶路的拖着尾巴；放大后标名字和去向；近两月的劫杀、夺宝打记号。
  - 调试：控制台 `__game.simDebug = true`，全图所有人连同去向连线，神识里的人头顶也标〈在干嘛〉。
- **世界见证**（`worldWitness`，见下）：附近修士看见异象、记成传闻；玩家突破筑基以上 → 本宗传讯道贺附贺礼、同盟宗门示好拉拢（宗门声望 +）、仇家里自觉还有一拼之力的那个动身来探虚实、胆小的仇家就此作罢；NPC 对你的称呼按境界与名声变（前辈 / 韩前辈 / 韩老祖 / 久仰大名）。NPC 结丹、结婴也出异象，你在附近能看到光环与提示。
- **随机数带种子**：世界模拟里的随机全部由（世界种子, 日子, 人）派生（`core/rng` 的 `mulberry32` + `hashU`），他图发生的事与玩家站哪儿无关（`test-sim` 验证同种子两次一致）。
- **顺手修**：`foemind.ts` 判断顺序——被威压镇住（sup≥2，rooted）的劫修以前先 `return`，永远不会求饶；现在先判「见高人」，跪地求饶，威压一松便逃。`test-demog` 全过。
- `relations.ts`：NPC 之间的仇杀不再掷骰子定生死，交给 sim 的追杀目标。
- `test-demog.ts` 第 2 段改测新设计：「劫修不再凭空生成在你神识圈外」+「真实劫修的境界不随主角境界变化」。

## 给其他分支的接口
- **s2-break（突破）**：突破成功时调用
  ```ts
  import { worldWitness } from './sim/witness';
  worldWitness(game, { kind: 'break', who: 'hero', realm: h.realm, stage: h.stage });
  ```
  返回一条传闻事件。也可传 `x / y / map / text` 覆盖默认。NPC 的结丹结婴 sim 内部已自动调用。
- **s4-content（地域 / 宗门掉落表）**：
  - 配装：`setKitProvider((ctx) => ({ bag, main, gongfa }) | null)`（`src/world/sim/kit.ts`），ctx 里有 `map / zone / home / sect / faction / realm / stage / pers / canon / rnd`；返回 null 回落默认配装。
  - 掉落：`NpcWorld.dropLootOf(d, x, y)` 一个函数，里面调 `deathLoot(d)`（= 储物袋 + 灵石）。要接 `rollLoot`，改 `deathLoot` 或 `dropLootOf` 这一处即可。建议让 rollLoot 生成的东西在 NPC 生前就放进储物袋（走 provider），这样「打你用的 = 死后掉的」不会破。

## 存档兼容
- 新字段全是可选：`NpcData.bag / main / gongfa / xp / fame / aim / escort`，`WorldState.sim`。旧存档读入时 `outfit()` 按种子补家当，`ws.sim` 缺省自动新建（`test-sim` 里专门造了去掉这些字段的旧存档验证）。

## 测试与性能
- 新测试 `tools/test-sim.ts`：挂机 N 天（默认 120：实时层 30 天 + 闭关 90 天），验证真的移动（无瞬移）、真的成长、夺来的东西对得上、传闻里死的人确实死了、远处劫道与玩家位置无关、秘境被抢、风云榜、掉落 = 储物袋、化敌招式里有本命法宝、世界见证、存读档与旧存档。
- 新脚本 `tools/perf-sim.ts [帧数] [额外人数]`：只跑逻辑量 NPC 更新耗时。改前 / 改后（Node，本图 366 人；再塞 400 人共 766 人）：
  - 改前：npcs.update 平均 0.03ms / 0.05ms（旧版远处的人只是直线挪动、掷骰子）
  - 改后：平均 0.19ms，p95 0.64ms；766 人时平均 0.50ms，p95 0.94ms。偶有 20～30ms 的单帧（多半是 GC），慢车道分帧后已无固定周期的卡顿。
