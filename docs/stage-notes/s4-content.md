# 第 4 阶段（s4-content）：功法、法宝、神通满天下

## 数量

- **功法 106 门**：主修 68 · 辅修 28（神识 / 炼体 / 遁术 / 御兽 / 傀儡 / 阵法 / 符箓 / 炼丹 / 炼器 九门）· 秘术 10；每门都有玉简（`scroll_gf_*`），宗门功法只在本宗藏经阁 / 本宗地界掉落。
- **法术神通 259 门**（原 114）：14 系各补十来门，按“出手方式 × 品阶”模板定数值，手工命名、手写描述；另有各宗招牌神通 6 门、秘术 7 门。
- **法宝法器 834 件**（原 105）：手工精做 53 件（26 宗门弟子法器、27 件镇宗之宝、人物本命法宝）+ 生成 678 件。
- **出手方式 28 种**（原 16）：新增葫芦收摄、伞挡、扇风、连珠、罩子困人、塔镇、印压、灯照魂、梭遁、鞭、阵盘、傀儡 12 种，每种一个独立的出手逻辑（`world/artacts.ts` 末尾），特效全用现有特效库拼，未改 combatfx / gl/fx。

## 四层数据表（`src/data/canon/`）

- `types.ts`：地域 / 五行（含风雷冰变异、阴）/ 相生相克；
- `regions.ts`：天南 · 乱星海 · 大晋，各地五行偏向与风物；
- `factions.ts`：正道盟、越国七派、天道盟、魔道六宗、九国盟、慕兰、星宫、逆星盟、海外诸岛、大晋正道 / 魔道十宗、天澜圣殿；
- `sects.ts`：27 家宗门（天南 20、乱星海 4、大晋 3），每家：镇派功法、3～6 门法术、弟子常用法器、镇宗之宝（不外卖）、本门辅修 / 秘术；
- `people.ts`：23 位原著人物（第一批：南宫婉、温天仁、蛮胡子、六道极圣、乾老魔、极阴祖师），配本命法宝、招牌神通、主修功法——与你为敌时先上招牌神通（`schools.ts sigSkill`），杀之掉本命法宝与神通玉简；
- `gongfa.ts` / `spells.ts` / `artgen.ts`：功法、法术、法宝（含生成器）；`combos.ts`：套路；`rules.ts`：新物品流通规则；`loot.ts`：掉落池。

## 掉落按地域、宗门（`data/canon/loot.ts rollLoot(地域, 宗门, 档次, rng)`，接入层 `world/canonloot.ts`）

- 凡品、下品大路货各地都有（外地的也偶尔流过来）；中品以上只掉本地域的东西，乱星海 3000 次掉落一件外地中品都没有；
- 在宗门地界（地点 42 格内）或打的是该宗的人：本门弟子法器、本门法术 / 功法权重 ×9，本门五行的东西 ×2.4，别派秘传一概不掉；
- 镇宗之宝：杀宗门之主（掌门 / 老祖 / 元婴）必得，宗门元婴长老 8% 带在身上；
- 接入：`combat.ts kill()` 的随机卷轴改为 `canonDrops()`；`combat.randomScroll()` 改为按地域 / 宗门；`npc.ts onEnemyKilled` 两行改为 `npcCanonDrops()`；`sites/happen` 里调 `randomScroll` 的地方随之按地域。
- 敌人招式：在宗门地界遇到的修士 65% 是该宗的人（`schools.ts territory`），所以各宗地界打起来手感不同。

## 功法分门别类（`world/gongfa.ts`）

- **主修**：修炼速度、属性；“路子”（本门系别的法术 +12%～37%，同属性法宝 +60% 于此）；到境界自悟专属神通（如九阳焚天功 → 焚天印）；改修主修散去三成修为（长春功 / 吐纳术改修不损）；
- **灵根**：功法有五行。灵根含此属性修得顺（天灵根 ×1.35），不含 ×0.7，风雷冰异种功法无变异灵根 ×0.6；伪灵根韩立默认木水火土，修锐金诀明显慢于赤炎诀；
- **辅修**：筑基一门、结丹两门、元婴三门：神识（神识↑）、炼体（气血防御↑）、遁术（身法赶路↑）、炼丹（成丹率↑）、炼器（法宝威力↑）、御兽 / 傀儡 / 阵法 / 符箓（相应法宝、法术↑）；
- **秘术**：血遁折寿一年、血影遁三年、天魔解体十年并事后元气大伤、燃血术一年、燃魂一击修为倒退、逆脉回元修为倒退回满法力、九转回魂五年……
- 新面板「法 · 功法」：主修 / 辅修 / 秘术、灵根适配、专属神通、套路搭配、随身法宝的功法加成、此地出产。

## 套路搭配（`data/canon/combos.ts`）与五行

- 13 组：大庚剑阵（原有）、阴魂缠身、法体双修、大衍傀儡术、冰魄寒光、掌心雷珠、风助火势、周天星斗、摄魂灯照、万兽归葫、人剑合一、青木华盖、同门心法；出手时头顶飘「套路·…」；
- 五行相生：连续施展相生两系（木→火→土→金→水→木），每接一环威力 +12%（至多三环），飘「五行相生·木生火」；相克沿用原有的元素克制。
