# 第 2 阶段：境界突破改造（分支 s2-break）

## 节奏（硬核）
- **闭关要耗「心得」**（`src/world/ascend.ts`、`game.ts seclude()`）：
  - 心得在外面历练时攒（每真实秒 0.4 日）、斩敌一名得「战斗感悟」（心得 4×(1+境界) 日，外加几日修为）、去**悟道之地**打坐顿悟；
  - 有心得闭关比打坐专注（每日修为 ×2.2）；心得耗尽时「直到瓶颈」自动出关，定时闭关则闭门造车（一成之功）；
  - 心得有上限（炼气 900 日 … 元婴 20000 日），攒多了也只抵这么久的苦修。
- **闭关会被打断**：一到三年一次（境界越高越久，新开局头两年不打断），轮流出现：
  - 仇家上门（有仇人就是仇人亲自来，没有就是劫修循灵气波动找来，出关迎敌）；
  - 红颜求救（认识、好感 15 以上的红颜，玉符给出方位，六日内赶到，打退截杀者好感 +15，不去好感 -18）；
  - 宗门召集（十五日内回山门外清剿魔道探子，记贡献；不去扣 30 贡献）；
  - 兽潮（灵气外泄引来妖兽）。地图上标「救」「召」。
- **丹毒**：修为丹药跨境界累积丹毒（每颗 7+2×品阶），药力 ×(1−丹毒/115)；丹毒 60 以上气血 -10%，30 以上扣冲关成功率；打坐慢慢化去，**灵泉水**（-25）、**万年灵乳**（清零）可洗（角色面板按钮）。原有的同境界耐药保留。
- **悟道之地**（地图「悟」字）：太岳观云台、北寒冰心崖、极西枯骨道、阴阳窟两仪石、昆吾山古碑、坠魔谷魔痕壁、外海听潮礁、草原落日坡。在此打坐灵气 ×1.8，每处十年可顿悟一次（心得 + 修为）。
- **各境界所需修为**（`realms.ts` 的 `XK`）：炼气 ×3.2、筑基 ×3、结丹 ×2.8、元婴 ×2.5、化神 ×2（相对第 41 步）。
- **测算**（`npx tsx tools/pace-ascend.ts [old]`，玩法模型写在脚本开头：六成时间在外跑、四成打坐、每分钟去闭关一次、每小境界两颗丹、伪灵根）：

  | 到达 | 调前（第 41 步） | 调后 |
  |---|---|---|
  | 筑基 | 14 分钟（26 岁） | 1.3 小时（36 岁） |
  | 结丹 | 17 分钟（55 岁） | 7.1 小时（130 岁） |
  | 元婴 | 21 分钟（131 岁） | 22.2 小时（370 岁） |

  调前修为本身几乎不花真实时间（闭关一键到瓶颈），只取决于多快弄到丹药。调后：不吃任何延寿丹的模型玩家约 15% 在结丹期寿元耗尽——硬核，需要找寿元丹 / 灵乳 / 好灵根。剧情门槛和找材料的时间不计。

## 准备清单（冲关前在角色面板看得到）
修为圆满（瓶颈上继续打坐闭关「打磨根基」，炼气 90 / 筑基 720 / 结丹 2400 / 元婴 5000 日）、稀世灵物（各境界几选一，冲关时耗去）、灵脉洞府（灵气 ×1.5 以上）、护法人选（同行红颜 / 同伴 / 结拜，或宗门职位够高的长老）、心境（仇家不超过一个、声望不低于 -30）、法宝温养（快捷栏有合用法宝，打坐闭关累积）。每项 +7%（筑基）/ +6% / +5% / +4.5%。
面板同时列出：底子、丹药、灵根气运、准备、失败感悟、丹毒、重伤各加减多少，以及失败代价。
硬核底子：筑基 10%、结丹 5%、结婴 3%、化神 1%（旧版 12/8/5/3），封顶 92%。

## 突破关卡（`src/world/ascendRun.ts`）
- **筑基 · 引灵冲脉**：奇经八脉八个节点，光点绕圈，进金区按空格 / 点击（正中为上佳），越来越快；冲偏一次气血 -8%；发挥 ±15%。约 20–30 秒。
- **结丹 · 心魔三重 + 凝丹三转**：每转选文火（稳）/ 武火（六成大进、四成反噬吐血）/ 心头精血（折寿三年必进）。火候 + 准备 + 一点天命 → **金丹一到九品**，终身带着：属性 ±4%/品、修炼速度 ±3%/品（五品为常），存档里有。
- **结婴 · 心魔五重 + 碎丹成婴**：心魔幻境扩充到按经历生成（仇家、丹毒、前次失败、灵石贪念、凡俗爹娘、厉飞雨、孤身散修、杀伐，原有的血河 / 红尘 / 墨大夫 / 白发 / 宝瓶 / 同门 / 碎丹保留）；然后元婴凝形进度条约一分钟，漩涡引来三波外敌（结丹魔修，最后一波有元婴老魔），护法人选化作友军替你挡；离开阵眼 4 秒或气血见底**被迫中断**（按减半惩罚算失败）；敌人近身时凝形变慢。
- **化神 · 元神合一**：十方元气，同一个小玩法，更快更窄。

## 失败与防刷
- 失败：修为倒退三成、重伤（筑基 120 … 元婴 900 日内属性七折、冲关 -15%）、折寿（5/12/30/60 载）、约 10–18% 跌落一层（保留下一层八成修为）；留下一分感悟（下次 +6%，最多 4 分）。
- **天命种子**存在存档里（`hero.asc.seed`）：冲关的天命之数 = 种子 × 境界 × 已冲次数 × 准备指纹（清单哪几项、带几颗丹）。读档重来结果不变；只有准备变了才重算。关卡发挥、心魔选择会改成功率（这是本事，不是运气）。没有强制锁存档。

- 头顶灵气漩涡（乌云旋臂 + 发光旋臂 + 漩涡之眼 + 灵气倒灌光柱，半径约 1500），关卡中逐渐卷大，大地图标「旋」字和范围圈；
- 镜头拉远到 0.42 倍、两段慢动作；三个黑白水墨镜头（WebGL 后期 `stage.ts uInk`；无 WebGL 时 Canvas 合成兜底）；
- 满屏书法大字（「天地灵气倒灌而下」竖排 → 「筑基 / 金丹 / 元婴」+ 副题 + 朱印 → 「元婴出世」）；
- 元婴在头顶显化（盘坐小人、紫金光），元婴之后身上常带灵光，七品以上金丹也有淡淡金光；
- 音效（雷、钟、爆、破境），冲关时配乐切到最激烈的一档。
