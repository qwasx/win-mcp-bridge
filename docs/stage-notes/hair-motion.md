# hair-motion 分支：发型（重点）与动作优化

## 发型：新 `src/gfx/hair.ts`（全部代码绘制，配 AI 脸）
- **做法**：头发由三类部件拼成一整片剪影——
  - 发壳：贴颅骨、比颅骨略鼓（顶上更鼓，部分发型两鬓蓬起成蝉鬓），下沿就是发际线，脸那侧按发际线裁开露出 AI 脸；
  - 发髻 / 发环：3D 椭球取凸包（根部与头皮取并集）或沿 3D 曲线的发带；与发壳**先统一描墨边、再统一填色**，交界处没有接缝，不会像零件拼上去；高耸的发环、垂鬟、堕马髻挂弹簧，跑动时晚半拍地晃；
  - 会飘的：披发、马尾（先从发结拱起一段再垂落）、垂髾、鬓发 / 龙须、侧辫、发带、步摇——用原有布料条带模拟。
- **发际线贴合 AI 脸**：按 AI 脸的耳朵位置重做发际线（额前弧形、男子耳前竖直短鬓、头发从耳上绕过、耳后垂到下颌角、后颈发际）；中分为 ∧ 形、侧分一侧斜梳；刘海不过眉；步摇珠串往头外侧垂，不挡眼。可见发际线两端沿"头心→端点"方向裁出头外，转头时裁切线不再横穿后脑。
- **体积与层次**：整头共用一个左上受光的渐变；分缕发沟（长短不一）、锯齿状柔和高光带、中分发缝、发际淡墨线；白发上的发沟自动减淡；远景（屏幕上头小）自动少采样、不画细节。
- **发型（16 种，均 5 朝向 × 镜像 8 方向）**：
  - 男：束发冠、道髻插簪、高马尾、半披半束、披发（常配抹额）、短打束发（布带短结）、老者发髻（发际后退 + 短披发）；
  - 女：飞仙髻、双环髻、垂鬟分肖髻、堕马髻、双丫髻、半披半束、长直披发、高髻步摇、流云髻、侧编长发、高马尾、老妇发髻；光头保留（淡青发茬）。
- **头饰搭配**：冠、莲花冠套在发型给出的顶髻上（没有顶髻就补一个小髻）；头巾、抹额贴着该发型的发面；帷帽不配高髻；簪 / 步摇插在发型给出的位置。
- **分配**：`randomLook` 按身份 / 性别 / 年纪给发型（老者 → 老者发髻，少女脸 → 双丫 / 双环，帷帽不配高髻，冠不配马尾）；细分用由身高体型派生的小随机数，**不多消耗 rnd**，别处按种子生成的人群不变。
- **主线人物**（`storylooks.ts`）：墨大夫老者发髻、曲魂 / 贾天龙 / 万小山短打束发、金光上人 / 欧阳束发冠；**红颜**（`beauties.ts`）：南宫婉飞仙髻、董萱儿双环髻、陈巧倩垂鬟分肖髻、墨彩环双丫髻、紫灵流云髻、银月半披半束。
- 存档兼容：旧发型名（bun/crown/ponytail/long/twin/halfup/updo/bald）全部保留可用。

## 动作（`character.ts` 的 poseFor / CharState）
- 待机：重心在两脚间缓慢换（髋侧移、不吃重的腿微屈）；张望改为连续转头（原来一下跳过去）；跑停后有一下前冲余势再站稳；
- 走：脚跟先着地、着地时重心最低、骨盆移到支撑腿；手臂比腿晚半拍；
- 跑：摆臂更有力、肩随臂转，头抵消躯干扭转目视前方；
- 御剑：一前一后踏稳、膝吃住风压，越快越前倾低头，转向时向弯内侧倾，整体缓缓起伏；
- 施法：先蓄（含胸、手收腰侧、后坐）0.12 秒再猛地推出（略过头再回），然后保持剑指 / 立掌；
- 采集：蹲下后右手一伸一收地摘；受击：0.06 秒打到位、慢慢恢复带一点晃；闪避：先一沉再侧滑出，收回有余势；
- 转身头先转、肩跟上；动作切换按种类给不同过渡时长（受击 0.05s、跑停 0.3s、起降 0.32s……）；重心侧移时髋角反向补偿，脚不滑。
- 头发的风按画面缩放换算（放大预览时也一样飘），纵深方向的风按斜投影减弱；原地抖动比衣服小。
