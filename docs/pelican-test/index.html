Pelican Test

一只鹈鹕，骑着自行车

同一个提示词 —— Generate an SVG of a pelican riding a bicycle —— 喂给不同的模型，看谁会真的把「骑」画出来。这一只不是图片，是纯手写几何： 两条腿都算到踏板上，翅膀扶在车把上，全图零位图、零字体依赖。

这道题在测什么

空间关系

鸟得坐在车座上、脚在踏板上、翅膀在车把上。最典型的失败是鹈鹕悬浮在自行车上方 20 像素。

结构完整性

两个轮子同高、圆心对齐、车架闭合、链条连着牙盘和后飞轮。少一根管子，车就散架了。

概念组合

大喙、喉囊、蹼足这些鹈鹕特征，必须和自行车的几何拼成一个动作，而不是两件东西并排放。

这一版是怎么搭的

不是凭手感画坐标，而是先定几个锚点，其余全部推出来：

# 锚点
REAR_HUB  = (296, 470)   FRONT_HUB = (508, 470)   # 同一条 y，轮子才站得平
BB        = (400, 478)   # 中轴，比轴心略低
SEAT_TOP  = (344, 336)   HEAD_TOP  = (487, 336)   # 上管水平，车架闭合

# 腿：两段式 IK，反解膝盖位置，脚落在踏板圆上
pedal = BB + CRANK_R * (cos θ, sin θ)
knee  = two_bone_ik(hip, ankle, THIGH=106, SHIN=100)

# 曲柄转 1°，另一条腿就是 1° + 180°，所以永远一前一后

换来的是：脚跟踏板永远咬着，两个轮子和牙盘可以绕各自圆心转，而画面不散。 点上面的「让它骑起来」，看的就是这套 IK 在实时跑。
