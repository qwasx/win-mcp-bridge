# STARBASE LIVE · Roadster 倒置悬停坡道测试（Three.js + SVG）

夜间直播画面：德州 Starbase 测试场，强力工业泛光灯下，白色第二代 Roadster 风格跑车高速冲上巨型金属 C 形坡道，
到达 180° 完全倒置的顶端后靠车底吸附风扇悬停 1 秒；随后脱离，车底反推口持续喷白色高压冷气减速，
车身四周 RCS 冷气短脉冲（无明火）将车身 180° 翻正；接近地面时车底向下喷白雾形成气垫，四轮轻柔着地，悬挂压缩回弹。
手持长焦跟拍（焦距随剧情推拉 + 手持抖动），夜间镜头光斑（SVG），直播 HUD（SVG）。

## 打开
- 直接双击 `index.html`（离线可用，`app.js` 为打包好的单文件）。
- 空格 播放/暂停 · R 重播 · S 慢放（1× / 0.5× / 0.25×）· H 隐藏 HUD · 底部进度条可拖动。
- 自动循环：直播 → 0.5× 慢动作回放 → 直播 …
- URL 参数：`?t=7.2` 跳到指定秒；`?hud=0` 无 HUD；`?q=high` 2 倍超采样（显卡好时更清晰）；`?q=low` 省电。

## 物理时间线（src/timeline.js，确定性）
- 入坡 27.5 m/s（≈99 km/h）；坡道 = 缓和曲线(14 m) + 圆弧 + 缓和曲线(7 m)，顶部 18 m、航向 π（完全倒置），曲率二分求解。
- 坡道上能量守恒 + 滚阻/风阻，峰值约 7 g；顶部倒置直道吸附风扇锁死后 12.5 m/s² 制动、静止悬停 1.0 s。
- 下落：刚体积分；RCS 四次脉冲（两次加速、两次减速）角加速度求解为恰好 180° 横滚；
  反推按"高处恒减速、最后一米线性渐近"的导引律闭环，触地速度 ≈ 0.7 m/s；悬挂为弹簧-阻尼（ωn 10.2，ζ 0.33）。

## 结构
| 文件 | 内容 |
|---|---|
| src/timeline.js | 坡道曲线、行驶/下落/悬挂模拟，`state(t)` |
| src/car.js | 参数化放样车身 + 轮罩凹槽、座舱罩、空气动力轮毂、灯、反推口/RCS 口 |
| src/track.js | 钢板路面、护墙/扶手/LED、箱梁、远侧双层 C 形脊梁桁架、端部挡块与频闪 |
| src/env.js | 混凝土场地（接缝/积水/轮胎印/降落靶标）、夜空星星、泛光灯塔（SpotLight + 体积光锥）、灯车、远景 Starbase |
| src/particles.js | 冷气粒子（射流、撞路面/撞地铺开、光锥照亮） |
| src/post.js | Bloom + ACES + 直播机质感（色差/暗角/颗粒/调色） |
| src/overlay.js | SVG 镜头光斑（遮挡检测、星芒、拉丝、鬼影）+ 直播 HUD |
| src/main.js | 手持长焦摄像机、喷流发射、主循环、控制 |
