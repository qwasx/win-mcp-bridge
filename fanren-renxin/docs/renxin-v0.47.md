# 人心 · v0.47 补丁说明（尔虞我诈四件套）

> 凡人修仙，修的从来不只是灵气，是心眼。
> 本补丁只做一件事：**把信息从"全真"变成"七真三假"** —— 让玩家终于需要用人脉、声望、神识、阅历来自保。

改动全部长在现有骨架上：恩怨网（ties/hate）、眼下的打算（plan）、好感/仇怨（favor/grudge）、
心声泡（alive）、街头事件池（happen）、声望/悬赏/雇凶（relations）一个没扔，只加了一层"表里不一"。

---

## 一、表里系统：每个 NPC 两张脸

| 概念 | 落点 | 说明 |
| --- | --- | --- |
| `favor` | `npc.ts` NpcData | 真实态度，照旧参与所有 AI 决策 |
| `mask` | `npc.ts` NpcData（新增） | 表里之差（表演好感 − 真实好感），由性格驱动 |
| `shown(d)` | `world/deceit.ts` | 表演态度：对话语气、行礼/冷脸、**心声泡**都用它 |

- `ruthless / greedy` 的人 `mask` 最大：他打你储物袋主意时，反而对你更热络；
  `righteous / kind` 的人两值几乎相等（正人君子不装）。
- 心声泡改造（`alive.ts` `thoughtOf` / `drawMindBubble`）：
  - 你的境界 **≥ 对方两个大境界**，或**神识压制**（`a.sup ≥ 1`）→ 显示真心声，**泡边缘描金**；
  - 否则显示**表演心声**（"这位道友好生面善"，其实在打量你的袋子）；
  - **结丹以上、狠辣/贪婪的老魔**连被压制时的心声都是假的，要靠情报手段才能戳穿；
  - 有阅历的人，偶尔能听到一句破绽提示（"（他笑得有些过于热络了）"）。
- 对话标题里的好感改为**表演好感**，表里相差过大时挂一个 ⚑；「以神识探其虚实」才摊牌真实数值。

## 二、谎言与情报：把"消息"做成一个对象

```ts
interface Rumor {
  text: string;                 // 玩家看到的说法
  truth: 0 | 0.5 | 1;           // 假 / 半真 / 真
  src: string;                  // 谁说的（接 ties 网）
  motive?: 'honest' | 'bait' | 'smear' | 'proxy';   // 诚实 / 设饵 / 诋毁 / 借刀
}
```

- 游戏里**一切非亲眼所见的信息**都走 `Rumor`（`worldstate.ts` 存档，`world/deceit.ts` 生成与判定）。
- 「打听消息」不再天然为真：贪狠之人爱设饵，与你有仇的爱诋毁，谨慎的爱道听途说。
- 反制手段（全是修仙味）：
  1. **多方印证**——再寻一人对口径，假消息一对就对不上；
  2. **神识探查**——对信使用「探其虚实」；
  3. **灵石收买**——花钱问"这消息谁放出来的"；
  4. **赌一把**——不验证直接去，开放世界嘛。
- `relations.ts` 的"挑拨"从暗改好感数值，升级成**玩家看得见、会上当的假消息**（`motive: 'smear'`）。
- 江湖信义低的人，连真话都听不到：有人会直接拒答。

## 三、骗局池（`world/happen.ts` 新增 `scam` 事件，判定在 `world/deceit.ts`）

| # | 钩子 → 反转 | 状态 |
| --- | --- | --- |
| 1 | 合作探宝，分赃翻脸 | ✅ |
| 2 | 假丹药（三折"筑基丹"，实为淬体丹染色） | ✅ |
| 3 | 借刀杀人（"前面山谷有魔修害我全家"） | ✅ |
| 4 | 美人局（合欢宗扮柔弱求护送，夜里摄魂） | ✅ |
| 5 | 夺舍老魔（"求你渡一口灵力"，接触瞬间夺舍） | ✅ |
| 6–12 | 拍卖托 / 假悬赏 / 结拜图谋 / 渡劫局 / 洞府以次充好 / 商队夹带 / 血婴哭声 | 已写入 `data/scams.ts` 的市井老话，作为传闻与阅历内容 |

- 频率控制：骗局约占街头事件的 **两成**；同一类吃过一次亏，下次会降权，并给出"上次的教训"选项。
- 骗局按 `rollScam(遇到次数, 境界)` 抽取，`scamChance(性格)` 决定谁在骗人——谨慎的几乎不骗，贪狠高发。

## 四、玩家也能骗人（`Deceit.trickOpts`，挂在 NPC 主对话里）

- **报假名号**：冒充黄枫谷/掩月宗弟子唬人——被当场拆穿则信义大跌、声望受损、当场翻脸；
- **卖假货**：低品丹 + 伪灵粉当"上品丹药"卖——赚快钱，但恩怨网如实记账，买家按"被骗"记仇；
- **散布假情报**：花灵石让说书人放风"某处异宝出世"，把仇家调虎离山；
- **分赃下黑手**：合作探宝结算时永远有一个红色选项——杀人夺宝一时爽，ties 网里他的师门、道侣、结拜兄弟记你一辈子。

## 五、江湖信义 `ws.cred` 与阅历《韩立随笔》

- `ws.cred`：独立于正邪声望的**江湖信义**。骗人降，守信升。
  信义低了：没人与你同行、坊市压你的价、求救没人来、连打听消息都吃闭门羹。
- `ws.exp2`：阅历册。每次**识破 / 吃亏 / 学到**记一条（"曾被假藏宝图诱入伏击"）。
  阅历影响：假心声的破绽提示概率、鉴丹与识破成功率、多出"（你想起上次……）"的选项。
- **按 `X` 打开《韩立随笔》**（`ui/Notes.tsx`）：阅历 / 听来的消息（含印证结论）/ 骗术图谱 / 信义条。
  玩家翻自己的上当史——这本身就是叙事。
