# 凡人修仙传 2D 同人 · v0.44「山河元婴」补丁

基于 `fanren-v0.43-huoshijie` 源码包。只替换 `src/` 下同名文件，另新增两个文件。
`npm install` 后 `npm run dev` 即可；`tools/sim-pace.ts`（补丁包根目录为 `tools-sim-pace.ts`）可自行复核节奏。

---

## 一、节奏重定：把「随便一打就升级」彻底废掉

**问题**：v0.43 打一架就涨修为，二十来年就结婴了。原著里**两百年结成都算早**。

**改法**：修为只从「岁月苦修」里来。

| 文件 | 改动 |
|---|---|
| `src/data/realms.ts` | 各境界所需修为（`expDays`）整体上调；结婴瓶颈成功率微调，文案改为「心魔劫、天雷劫、因果劫三关」 |
| `src/world/cultivation.ts` | 奇遇/切磋/论道修为折算 `INSIGHT` **0.3 → 0.06**；丹药耐药 `PILL_FATIGUE` **0.55 → 0.42**（越吃越没用，逼你闭关） |
| `src/world/combat.ts` | 杀怪修为系数 **0.0045 → 0.0007**（猎妖是财源，不是修行） |

### 节奏实测（`npx tsx tools/sim-pace.ts`，一年按 360 天，起始 17 岁）

| 灵根×功法总倍率 | 结婴于第几年 |
|---|---|
| 2.00（天灵根 + 上乘功法） | **177 年** |
| 1.20 | 295 年 |
| 1.00（普通真灵根） | **353 年** |
| 0.85（三灵根） | 416 年 |
| 0.50（伪灵根） | 707 年 —— 结不成，寿元先尽 |

分段（rate=1）：炼气 13 层 ≈ 16 载 · 筑基三阶 ≈ 82 载 · 结丹三阶 ≈ 144 载 · 结丹大圆满在第 **242** 年，
再熬数十年方才触及元婴门槛。**两百年结婴，已是奇才**；三百年，才是常态。

## 二、结婴大典：七十万人观礼

**问题**：结婴是原著第一等大事，v0.43 里就是一行「结丹 → 元婴」的提示，太寒酸。

**改法**：新增 26 秒全屏典礼，碎丹成婴那一下给足排场。

| 文件 | 说明 |
|---|---|
| `src/world/jieying.ts`（新增） | 典礼事件总线 + 观礼人数推算 |
| `src/ui/JieyingCeremony.tsx`（新增） | 全屏 Canvas 特效 |
| `src/world/game.ts` | 结婴成功时触发 `jieyingCeremony()`：从**真人名册**里挑各宗长老、故交、仇家组成观礼名单，发天下帖 |
| `src/ui/GameView.tsx` | 挂载 `<JieyingCeremony />` |
| `src/styles.css` | 典礼 UI 样式 |

**特效清单**：九色霞光自天门倒卷而下（九道光柱各自相位不同步）· 天河倒卷（群星逆旋收缩）·
金莲三千里次第开放（花瓣自湖面、江面、山头随机生起）· 花瓣雨 · **九道天雷依次劈落**（每道分叉、闪白、雷声）·
元婴自霞光中升起、端坐金莲之上 · 底部**观礼人数从 0 滚到 70 万+** · 观礼名单逐条浮现（令狐老祖、李化元、南宫婉……
来自你这局真实的 NPC 名册，谁活着谁来）· 天下帖全文告示。

点任意处跳过；`prefers-reduced-motion` 下自动降为短时静帧。

## 三、山河志：把地图填满

**问题**：地图太空，走半天见不着一处景，也没有像样的江河湖泽。

### 3.2 大江

- **沧澜江**（宽 3.2）：源自天澜草原南缘，经落霞大湖出水口，九曲东南注入无边海，沿途可渡可航

- **响水涧**：大晋朔州舜江支流
- 原有河道一并加宽
