# 活世界 · 凡人修仙传 2D（v0.43 · 代号「活世界」）

这版不改画面，改「人」。目标只有一个：**让 NPC 活起来** —— 他们有自己的储物袋、自己的功法、自己的门派、自己的家人、自己的仇恨、自己的社交，任何时刻都答得出「我在干嘛、我为何在这、我恨谁、为何恨」。任何人来找你，都必须带着**缘由**。

## 原来的毛病（这版修掉的）

| 原来的样子 | 现在 |
|---|---|
| 有人没头没脑地把主角喊过去 | 邀约必须有「缘由 + 利益 + 拒绝的代价 + 时限」，同一人 40 日内不来第二回，全世界约每 25 日才来一件 |
| 劫道的、追杀的总在路边等主角 | 劫道先算「有没有人真有理由动你」：有血仇 / 恶名在外 / 露过财才来，否则他们去拦别人的商旅 |
| 杀了人，世界毫无反应 | 亲族记**血仇**（会追到你头上）、目击者看在眼里、坊市里传出风声，他的储物袋真的落到你手里 |
| NPC 死了东西凭空消失 | 遗物归亲族承继；无人承继则落入旁人之手——还会有人说来路不正 |
| NPC 只是站着发呆 | 每人有日程：修行、采药、猎妖、做买卖、门中差事、闭关、回家、走动感情、授业、寻仇 |
| 世上没人认识谁 | 家户、结拜、师徒、道侣、生意伙伴；传闻沿关系网传播，越传越歪（有可信度） |

## 新东西在哪

**共享引擎（浏览器与服务器共用同一份代码）**

- `src/lib/alive/types.ts` —— 一切数据结构：储物袋、功法、亲缘、社交、仇恨、债务、需求、日程、传闻、邀约
- `src/lib/alive/content.ts` —— 门派 / 功法 / 物品 / 来路 / 性格 / 邀约口吻 / 家训 / 地名
- `src/lib/alive/world.ts` —— 世界模拟：日程选择、日程结算、衰老寿元、突破、命案与遗物承继、血仇代偿、传闻传播、**有缘由的邀约**
- `src/lib/alive/roster.ts` —— 默认名册（各门派名册、散修行商凡人、原著风味人物）
- `src/lib/alive/index.ts` —— 存取（`serialize` / `deserialize`，可进存档也可进数据库）
- `tools/test-alive.ts` —— 快速自检（700+ 日世界推进，几秒跑完）

**游戏侧接入**

- `game/src/world/alive/alive.ts` —— 桥接：把游戏内 `NpcWorld` 名册接进引擎；每日结算后把「仇恨 + 缘由、好感」写回游戏；把世界大事播成传闻；把邀约变成传音符
- `game/src/ui/AlivePanel.tsx` —— **活世界面板**（游戏内按 **Y**）：有缘之邀（应 / 推）、众生（人人可见袋子 / 功法 / 家人 / 恩怨 / 此刻在忙）、大事记、风闻
- `game/src/world/npc.ts` —— 挂上 `alive`：每日推进、死亡登记、**杀人后储物袋真的易主**、切磋记账、对话新增「**看看他的日子（活世界）** / 命册」、问候里带上他此刻在忙什么与为何恨你
- `game/src/world/happen.ts` —— 劫道、追杀改为**有由头**才发生，问头一句就把缘由说清楚

**世界后台（玩家不在，世界也照常过日子）**

- `src/db/schema.ts` —— `worlds`（世界快照 jsonb）+ `chronicle`（大事记）
- `src/lib/world-store.ts` —— 服务端载入 / 推日 / 落库
- `src/app/page.tsx` —— 活世界面板（网页版）：概况、有缘之邀、大事记、众生、门派、人家，可一键「过 10 / 60 / 240 日」
- `src/app/api/world/route.ts`、`src/app/api/world/tick/route.ts`、`src/app/api/alive/sync/route.ts`

## 跑起来

```bash
# 游戏本体（Vite + React + WebGL）
cd game && npm install && npx vite build && cd ..
rm -rf public/game && cp -r game/dist public/game   # 让 Next.js 把游戏挂在 /game/index.html

# 世界后台（Next.js + PostgreSQL）
npm install
npx drizzle-kit push --config drizzle.config.json
npm run build && npm start        # 首页是活世界面板，/game/index.html 是游戏
```

游戏里：**Y** 活世界面板 · **T** 与人交谈（新增「看看他的日子（活世界）」） · **I** 衣橱 · **H** 红颜录。

## 快速自检（不用等太久）

```bash
game/node_modules/.bin/tsx tools/test-alive.ts
```

会推 1120 天世界，并断言：有人出生 / 成亲 / 死亡 / 命案 / 寻仇；人人答得出自己在忙什么；人人有储物袋与功法；**每一次邀约都带缘由**（做不到就报错）；邀约频率不超过每 20 日一件。样例输出：

```
第 720 日 · 在世 309 · 人家 16 · 门派 30
生 30 · 婚 59 · 亡 48 · 命案 11 · 寻仇 7 · 买卖 21914
邀约 45 次 / 1120 日 ≈ 每 24.9 日一次（全部带缘由，且同一人不来第二回太快）

—— 命册样本 ——
温凝素 · 结丹期初 · 淡泊 · 黄枫谷
此刻：猎妖 · 妖兽伤了好几个同门，得去清一清
功法：太清凝气诀(2阶100层，黄枫谷所传)；百巧炼器诀(2阶96层，冯儿湘指点过几日)…
袋子：九曲灵参×1(越京采的九曲灵参)、庚精×1(彭道风的遗物)…
家人：彭道风(道侣)、彭海远(子女)
恩怨：吕仁青:劫了我千年灵乳；唐秋水:天魔宗的人杀了我同门
```

## 设计取舍

- **引擎与游戏共用一份代码**：游戏（Vite）通过 `@alive` 别名引用 `../src/lib/alive`，服务器直接 `import`。同一个世界，两边都能跑。
- **确定性**：世界由 `seed + day` 决定，服务端可以离线推日，读档也能按天重放。
- **游戏为真，世界为辅**：境界、生死、所在以游戏名册为准；活世界只补「日子」与「缘由」，并把结论（恨谁、为何恨、好感）写回游戏原有字段（`grudge / why / favor`），所以旧的追杀、压制、对话系统全部照常生效，只是**从此都有了说法**。
- **武力预算**：世界一天最多出一条人命（约每 40 天轮到一次），其余寻仇点到为止。江湖不是屠宰场。
- 活世界状态存进 `ws.flags.alive`（随原存档走），不改动存档格式。
