0.3 "玩"的实测印象

我顺着代码把一个玩家的典型一小时走了一遍（主线序章 → 自由期 → 坊市 → 野外 → 奇遇 → 斗法 → 被击倒）。系统广度惊人： 作息、营生、心声、恩怨网、宗门名册、战争、寿元、天象……但广度堆出来的是"热闹"，不是"紧张"。 下面说为什么。

一、诊断：这个世界"活"了，但不"险"

1.1 核心判断一句话

现在的众生系统做到了"人人有日子过"，但没做到"人人有欲望、且会为欲望骗你"。 修仙世界的本质张力 = 资源有限 + 寿元有限 + 人心不可测。前两条 v0.45/0.46 已经补得很好，第三条几乎是零。

1.2 证据（直接从代码里数出来的）

  • 全部 src/world/*.ts + src/data/*.ts 里，"骗"字只出现 2 次；"背叛 / 出卖 / 暗算 / 设局 / 圈套 / 构陷"加起来只有 events.ts 一处沾边； "夺舍"只存在于序章剧情（墨大夫，story.ts），开放世界里一次也不会发生。
  • NPC 的恶意全是明牌的阳谋：劫道是当面要钱（happen.ts）、仇人是见面就动手（relations.ts grudge≥1）、 悬赏是公开张贴。没有任何一个 NPC 会笑着接近你然后捅刀。
  • 游戏里所有信息都是真的：toast 是真的、传闻是真的、藏宝图是真的、求救是真的、传音玉符是真的。 玩家从第一分钟就学会了"字面意思全信"，于是所有决策都退化成数值比大小。
  • v0.46 的"心声"系统反而把最后一点深浅给抹平了：走近任何人，他头顶的云朵泡直接显示真实内心 （alive.ts drawMindBubble，连"贪婪者盯着你的储物袋"都明写）。等于全桌亮牌打麻将—— 这是本版本最用力、也最伤"尔虞我诈"的一个功能。
  • 死亡没有牙齿：game.ts onPlayerDown() 的全部代价 = 感悟池里 10% 修为 + 10% 灵石 + 2 件随机杂物 + 回城躺 3 天。 没有道伤、没有储物袋被搜、没有法宝被夺、没有仇家补刀。原著里韩立每一次保命都倾家荡产，我们这儿被元婴老魔打死 跟在野外淋了场雨差不多。
  • 资源不逼人抢：坊市按 market.ts 的区域规则无限补货，灵草野外刷新。血色禁地"没有同门只有敌人"的味道是对的， 但出了禁地，整个开放世界里没有第二处"我要的东西在你手里"。

1.3 为什么"难度不高"其实是同一个问题

节奏（天道）已经压到原著水平了——38 岁筑基、296 岁元婴，时间难度够了。 现在缺的是决策难度：玩家没有需要带着怀疑做的决定，没有做错会真疼的决定。 把下面第二章的"人心"做进去，难度自然上来，而且是"修仙小说的难"，不是"怪物血条翻倍的难"。

二、方案：給世界装上"人心"——尔虞我诈四件套

原则：全部长在现有骨架上。hate/ties（恩怨网）、plan（眼下的打算）、favor/grudge、心声、happen（街头事件池）、 relations（声望/悬赏/雇凶）这些系统一个不扔，只给它们加一层"表里不一"。

2.1 第一件：表里系统——每个 NPC 两张脸（工程量 ★★）

现状：NpcData.favor 一个数，既是他对你的态度，也是他表现出来的态度。

改法：拆成两层——

favor   → 真实态度（照旧参与所有 AI 决策）
shown   → 表演态度（对话语气、心声泡、行礼/冷脸用这个）
  • shown 由性格驱动偏差：ruthless/greedy 的人 shown = favor + 伪装值（他贪你的储物袋时反而对你更热情）； righteous/aloof 的人两值几乎相等（正人君子不装）。
  • 心声泡改造（关键！这是现成的显示管道）：
  • 你的境界 ≥ 对方 2 个大境界，或神识压制（suppress.ts 已有 sup 等级）→ 显示真心声（泡边缘描金）；
  • 否则显示表演心声——贪婪者心声是"这位道友好生面善"，其实在打量你的袋子；
  • 老怪物（结丹+ 且 ruthless）连被压制时的心声都是假的，要靠下面 2.2 的情报手段才能戳穿。
  • 这一改，v0.46 最大的投入（心声）从"剧透器"变成"读心博弈"：看穿人心本身成了修为的奖励， 完全符合"神识"的设定，一行不浪费。

2.2 第二件：谎言与情报——把"消息"做成一个对象（工程量 ★★★）

现状：所有消息直接 toast / 对话写死，天然为真。

改法：加一个 Rumor 类型，游戏里一切非亲眼所见的信息都走它：

interface Rumor {
  text: string;          // 玩家看到的说法
  truth: number;         // 0 假 / 0.5 半真 / 1 真
  src: string;           // 谁说的（接 ties 网）
  motive?: 'honest' | 'bait' | 'smear' | 'proxy';  // 诚实 / 设饵 / 诋毁 / 借刀
}
  • 藏宝图可能画的是伏击圈；"某地异宝出世"可能是魔修聚人头的局；有人托你带信，信里写的是"持信人可杀"。
  • 玩家的反制手段（全是修仙味的玩法）： 1. 多方印证——同一传闻去问第二个来源，truth 低的会对不上（茶楼说书人、坊市掌柜就是现成的情报节点，v0.46 刚画好的吃茶/说书场景直接复用）； 2. 神识探查——对信使用 2.1 的读心； 3. 灵石收买——花钱买"这消息谁放出来的"； 4. 赌一把——不验证直接去，开放世界嘛。
  • relations.ts 里已有"人与人之间会传话：挚友美言、仇人诋毁挑拨"的雏形——把"挑拨"从好感数值暗改，升级成玩家看得见、会上当的假情报，就是这套系统的第一个用户。

2.3 第三件：骗局池——12 个开放世界骗局模板（工程量 ★★★，可逐个上线）

照 happen.ts 现有事件池的写法（每个 60–150 行），按优先级排：

# 骗局 钩子 → 反转 复用的现有系统
1 合作探宝，分赃翻脸 散修邀你同探遗府（现有组队/护法），开到宝箱那一刻他出手 melee 组队、sites 遗府、2.1 表里
2 假丹药 / 假玉简 坊市地摊三折"筑基丹"，服用才知是淬体丹染的色；玉简是残篇 market、items；衍生鉴定玩法（神识扫描/找丹师掌眼）
3 借刀杀人 "道友，前面山谷有魔修害我全家"——其实是他的宿敌，你杀完背上血仇 hate/ties 血仇网原样接住后果
4 美人局 合欢宗（hehuan 已在魔道六宗表里）修士扮柔弱求护送，夜里摄魂 happen 护送事件反写
5 夺舍老魔 重伤"前辈"求你渡一口灵力，接触瞬间夺舍判定（神识对抗，败了进心魔战） xinmo 幻境战直接复用！
6 拍卖托 大城拍卖会上有托抬价（garrison 大城已有坐镇名册当托） market、大城系统
7 假悬赏 榜上"妖修"其实是得罪了贴榜人的正派散修，杀了才知道 悬赏系统反写、rep 反噬
8 结拜图谋 主动求结拜的"义兄"看上的是你的功法/本命法宝，熟了之后下药 bond 结拜系统
9 渡劫局 求你护法的人，劫云里混着他雇来趁劫出手的杀手——护法的你是真正目标 happen 渡劫事件已有三方，加一方
10 洞府以次充好 牙人卖你"上品灵脉洞府"，住进去发现灵脉早被抽干 home 洞府系统
11 商队夹带 护送报酬异常高的商队，箱子里是魔道的"货"，半路正道执法队把你当同伙 caravan + 宗门声望
12 血婴哭声 荒野小孩哭着求救——血婴傀儡，围上来的是炼它的魔修 魔修祭坛事件延伸

频率控制：骗局占同类事件的 15–25%（谨慎性格的 NPC 几乎不骗、ruthless/greedy 高发）， 让玩家保持怀疑但不至于草木皆兵；每类骗局上过一次当后，角色获得对应"阅历"条目（见 2.5），下次有辨识加成——吃亏长记性，这就是修仙小说主角的成长曲线。

2.4 第四件：玩家也能骗人——自由度的另一半（工程量 ★★）

尔虞我诈不能只许 NPC 放火：

  • 报假名号（happen.ts 劫道里已有"虚张声势"，把它推广成通用对话选项）：冒充黄枫谷执法弟子吓退散修——被真弟子撞破则宗门声望大跌；
  • 卖假货：地摊可以上架染色丹药（炼丹系统低品丹 + 一味"伪灵粉"）——赚快钱，但 hate 网如实记账，被识破的买家按"被骗"记仇、找你寻仇、坏你名声；
  • 散布假情报：花灵石让说书人放风"某处异宝出世"，把仇家调虎离山——他若活着回来，知道是你；
  • 分赃时刻：组队探宝的战利品结算屏上，永远有一个红色选项。杀人夺宝一时爽，ties 网里他的师门、道侣、结拜兄弟记你一辈子（这套报复链 relations.ts 已经写好了，就缺这个入口）；
  • 信誉是硬通货：新增 ws.cred（江湖信义，独立于正邪 rep）。骗局得手降 cred，低 cred 的玩家——没人跟你组队、坊市压你价、求救没人来。骗子玩法玩得起，但世界会用自己的规则回敬你——这就是开放世界该有的自由与代价。

2.5 阅历系统（把上当变成成长，工程量 ★）

ws.exp2（阅历）：每次识破/吃亏记一条（"曾被假藏宝图诱入伏击"）。阅历影响： 假心声的破绽提示概率、鉴定成功率、对话里多出"（你想起上次……）"的选项。 面板上做成一本《韩立随笔》，玩家翻自己的上当史——本身就是叙事。

三、难度：让"死"有牙齿，让"强"有代价

时间难度（天道）已经够了，不要再加倍修为需求——再压就逼玩家挂机了。要加的是风险难度。

3.1 重做战败（工程量 ★★）

现在 onPlayerDown() 太温柔。改成看敌人是谁：

击倒你的是 后果
妖兽 现状逻辑（它只想吃肉，你被路人所救）+ 道伤
劫修/仇家 储物袋被搜走（非装备栏物品 70–100%），生成"寻仇夺回"追踪：他会花你的钱、卖你的药——去晚了东西真没了（living.ts 的 NPC 买卖系统现成消化赃物）
死敌（grudge=2） 直接补刀 → 存档点复活（见 3.2 难度分层），或触发替身符/舍身保命消耗链
魔修 小概率被掳走炼宝，醒来在魔修洞府里，自己逃（潜行/爆发微玩法）

道伤：战败附加 7–60 天的"经脉受损"（修炼速度 -40%、法力上限 -20%），要灵药+闭关才好—— 把"别被打倒"从口头警告变成肌肉记忆，还给疗伤丹/疗伤系红颜事件一个真实用途。

3.2 道心难度分层（保自由度的标准答案，工程量 ★）

开局（和入魔/正道选择放一起）选道心，可单向上调不可下调：

  • 天骄：现状规则（新玩家/剧情党）；
  • 凡人（默认推荐）：3.1 全套 + 骗局池全开 + 资源限供；
  • 天道：单存档自动盖写、死亡即碑——死后生成一座刻着你生平（bio 系统现成的！）的碑，立在你陨落处，下一个存档的世界里能遇到。前任的储物袋就在那个杀了你的 NPC 身上。

3.3 敌人 AI 加"心眼"（工程量 ★★，foemind.ts 里改）

  • 诈败：ruthless 敌人血量 40% 时假装遁逃，把你引进同伙包围圈（反用现有"追杀准备 prep"字段）；
  • 渔翁：你和妖兽打到残血时，旁观的 greedy 修士才动手——把 v0.45"鹬蚌相争"事件反过来扣在玩家头上；
  • 先礼后兵：高阶敌人先传音勒索（交出三成灵石饶你），给钱是真饶——但他记住你好欺负，下月再来；翻脸打赢他，这一片的劫修都绕着你走（接 sense.ts 恶名传播）。

3.4 资源限供（工程量 ★★）

  • 坊市丹药/灵草按月限量（结合 market.ts 的 pz 产区概念），筑基丹主药全天南每年就出那么多株——注意节奏模拟要同步跑，别把韩立式玩家的丹药断供成苦修派；
  • 高价值灵草被你采到一半时，有概率"另一道神识也锁定了这里"（sense.ts 现成的锁定提示）→ 来人可谈、可分、可抢—— 血色禁地的味道，洒进整个开放世界。

每步都加对应 tools/test-*.ts（骗局触发率、战败掉袋追回链、cred 传播）， 并且把 test-tiandao.ts 扩一个"凡人难度韩立式"档——确认加了难度之后元婴年龄仍在 250–320 岁区间。

五、最后说两句

这个项目的底子是我见过的同人项目里最扎实的一档：恩怨网、名册、寿命、作息，全是真模拟不是贴纸。 缺的不是系统，是"系统之间会说谎"。 把信息从"全真"变成"七真三假"，把败北从"挠痒"变成"割肉"， 现有的 46,000 行立刻全部活过来——因为玩家终于需要用上这个世界提供的一切（人脉、声望、神识、阅历）来自保了。

凡人修仙，修的从来不只是灵气，是心眼。
