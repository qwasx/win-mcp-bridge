# 雨の夜のコンビニ角 — 雨夜便利店街角 · 三渲二微缩景观

一个 **Three.js / WebGL** 制作的雨夜日式便利店街角微缩三维场景。
自由拖拽旋转、滚轮缩放，纯 3D 观看体验 —— 没有任何 UI 界面元素（俯仰/距离受限的轨道相机 + 轻微自动环绕）。

![风格](https://img.shields.io/badge/风格-三渲二%20·%20日式动画-7f9fff) ![引擎](https://img.shields.io/badge/引擎-Three.js%20·%20Vite-88cc88) ![渲染](https://img.shields.io/badge/渲染-WebGL2%20·%20轮廓线%20·%20辉光-ffb366)

## 快速开始

```bash
cd diorama
npm install
npm run dev      # 开发服务器（已在预览端口运行）
npm run build    # 生产构建 → dist/
npm run preview  # 预览生产构建
```

## 观看方式

- **拖拽** 旋转视角 · **滚轮** 缩放 · **右键拖拽** 平移（俯仰与距离有合理限位，保持"模型感"）
- 默认镜头缓慢自动环绕（一旦操作立即让位）
- 整个场景搭在一个 16m × 16m 的方形展示底座上，正面有黄铜铭牌

## 美术要点（三渲二）

- **MeshToonMaterial + 阶梯渐变**：自定义 gradientMap（背面零光比、正面分段）
- **轮廓线**：深度 + 法线边缘检测的屏幕空间描边（墨色随亮度变化）
- **UnrealBloom + Neutral Tone Mapping**：夜景霓虹辉光但不过曝
- **自定义 Rim Light / 半球环境光**：干净的动画式明暗层次
- **Canvas 程序化纹理**：全部贴图（招牌 / 海报 / 路绘 / 货架商品等）均程序生成，无外部素材
- **Noto Sans JP**（`@fontsource`）：任何系统都能正确显示日文招牌

## 技术结构

```
diorama/
├── index.html          # 入口（无 UI，仅画布）
├── vite.config.js
└── src/
    ├── main.js         # 场景装配 / 灯光 / 后期 / 动画循环 / 轨道相机
    ├── materials.js    # 三渲二材质、渐变、湿地反射、光源注册表
    ├── textures.js     # Canvas 程序化贴图（路面 / 招牌 / 海报 / 商品…）
    ├── helpers.js      # 几何工具 / 合批器 / 商品 InstancedMesh / 电线
    ├── ground.js       # 展示底座 + 路面 / 步道 / 水洼 / 侧沟
    ├── store.js        # 便利店外观 + 可透视店内陈设
    ├── props.js        # 贩卖机 / 电柱 / 信号灯 / 护栏 / 公寓 / 小巷
    ├── rain.js         # 雨 / 檐滴 / 玻璃水痕
    ├── postfx.js       # EffectComposer：辉光 + 轮廓线 + FXAA
    └── debug.html/js   # 开发用：贴图检查页
```

- 渲染管线：场景(+深度) → 法线通道 → 合成（Bloom → 轮廓线 → Neutral Tonemap → FXAA）
- 帧率友好：约 320 draw call / 2.2 万三角面，材质合批 + InstancedMesh
- 调试 URL 参数：`?cam=front|top|store|close|interior|alley|parking`、`?flat=1`、`?freeze=1`

## 本地系统要求

现代浏览器（Chrome / Edge / Safari / Firefox，需 WebGL2）。首次 `npm install` 后即可离线运行。
